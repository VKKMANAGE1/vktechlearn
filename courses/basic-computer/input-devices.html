Input Devices — Keyboard, Mouse, Scanner और बाकी

लेसन 7 / 21·~6 मिनट·by Vïnâý Kúshwâhå

Input device वह उपकरण है जिसके ज़रिए हम कंप्यूटर को डेटा और निर्देश देते हैं। बिना input के कंप्यूटर को पता ही नहीं चलेगा कि करना क्या है। इस लेसन में रोज़ इस्तेमाल होने वाले input devices, उनके बटन और उनके बीच का फ़र्क़ देखेंगे — यह टॉपिक परीक्षाओं में भी सीधे पूछा जाता है।

Input device किसे कहते हैं

जो भी डिवाइस यूज़र से डेटा या कमांड लेकर उसे कंप्यूटर के समझने योग्य रूप में बदलता है, वह input device है। जैसे keyboard आपके दबाए बटन को सिग्नल में बदलता है, mic आवाज़ को डिजिटल सिग्नल में।

1. Keyboard

सबसे आम input device। इसमें लगभग 104 keys होती हैं, जिन्हें चार हिस्सों में बाँटा जा सकता है:

  • Alphanumeric keys: A–Z, 0–9 और punctuation — टाइपिंग के लिए।
  • Function keys: F1 से F12 — शॉर्टकट के लिए।
  • Navigation keys: Arrow keys, Home, End, Page Up/Down, Insert, Delete।
  • Numeric keypad: दाईं ओर अलग नंबर पैड, तेज़ हिसाब के लिए।

विशेष कीबोर्ड भी होते हैं — multimedia keyboard (आवाज़/वीडियो बटन के साथ), wireless keyboard (Bluetooth/USB receiver) और virtual keyboard (स्क्रीन पर)।

2. Mouse

GUI में काम करने का मुख्य साधन। इसमें बाएँ-दाएँ बटन, बीच में scroll wheel और नीचे optical sensor होता है। क्लिक, डबल-क्लिक, right-click (context menu), drag और drop — यही चार काम सबसे ज़्यादा होते हैं। Laptop में अलग mouse की जगह touchpad होता है।

3. Scanner

कागज़ पर छपी तस्वीर या दस्तावेज़ को कंप्यूटर में डिजिटल रूप में लेने के लिए। स्कैन की गई फ़ाइल आमतौर पर JPG या PDF बनती है। आज मोबाइल ऐप्स भी कैमरे से स्कैन का काम कर देते हैं, पर दफ़्तरों में flatbed scanner अब भी इस्तेमाल होता है।

4. Microphone

आवाज़ को इलेक्ट्रिक सिग्नल में बदलता है — voice call, recording, voice typing और AI असिस्टेंट के लिए। Laptop में built-in mic होता है, और बेहतर quality के लिए external mic लगाया जाता है।

5. Webcam

वीडियो कॉल, ऑनलाइन क्लास और फोटो के लिए। यह लगातार फ्रेम भेजता है, इसलिए इसे input device माना जाता है।

OMR, OCR और MICR में फ़र्क़

ये तीनों नाम परीक्षाओं में अक्सर उलझा देते हैं, इसलिए साफ़ समझ लें:

  • OMR (Optical Mark Recognition): पेन से भरे गोले पढ़ता है — जैसे प्रतियोगी परीक्षा का OMR sheet।
  • OCR (Optical Character Recognition): छपे हुए अक्षरों को पढ़कर editable text बनाता है — जैसे स्कैन किए हुए पेज को Word में बदलना।
  • MICR (Magnetic Ink Character Recognition): चेक के नीचे चुंबकीय स्याही से छपे नंबर पढ़ता है — बैंक में चेक प्रोसेसिंग के लिए।
याद रखें
  • Input device = डेटा कंप्यूटर की ओर
  • Keyboard, mouse, scanner, mic, webcam, barcode reader
  • Touch screen input + output दोनों है
  • OMR = गोले, OCR = अक्षर, MICR = चेक के चुंबकीय नंबर

आगे क्या

अगला लेसन output devices का है — monitor, printer, speaker और projector। वहाँ साफ़ हो जाएगा कि soft copy और hard copy में क्या फ़र्क़ है और प्रिंटर कितने प्रकार के होते हैं।

Practical — 5 मिनट

अपने कंप्यूटर से जुड़े सारे input devices की सूची बनाएँ। हर एक के आगे लिखें कि वह किस रूप में डेटा भेजता है — टेक्स्ट, आवाज़, तस्वीर या मूवमेंट।
