Chapter 1 · Computer Basics

Computer Hardware — CPU, Motherboard, RAM, ROM और Ports

लेसन 4 / 21·~8 मिनट·by Vïnâý Kúshwâhå

कंप्यूटर के अंदर जो चीज़ें छूकर महसूस की जा सकती हैं, वे सब Hardware हैं — CPU, motherboard, RAM, हार्ड डिस्क, कीबोर्ड, माउस, मॉनिटर। सॉफ्टवेयर उसे चलाता है, पर काम सारा हार्डवेयर ही करता है। इस लेसन में अंदर के हिस्सों को एक-एक करके समझेंगे, ताकि अगली बार कंप्यूटर खरीदते या धीमा होने पर समस्या पकड़ते समय आपको अंदाज़ा हो कि कहाँ देखना है।

कंप्यूटर सिस्टम के दो हिस्से

हार्डवेयर को मोटे तौर पर दो भागों में बाँटा जाता है:

  • Internal (अंदरूनी): CPU, motherboard, RAM, ROM, हार्ड ड्राइव, PSU, कूलिंग फैन, ग्राफ़िक्स कार्ड।
  • External (बाहरी, Peripheral): Monitor, keyboard, mouse, printer, speaker, scanner, UPS, पेन ड्राइव।

1. CPU — कंप्यूटर का दिमाग़

Central Processing Unit सारे निर्देशों को समझकर चलाता है। इसे तीन हिस्सों में समझ सकते हैं:

  • ALU (Arithmetic Logic Unit): जोड़-घटाव, गुणा-भाग और तुलना (बड़ा/छोटा/बराबर) करता है।
  • CU (Control Unit): बाकी सभी हिस्सों को निर्देश देता है कि कब क्या करना है।
  • Registers: बहुत छोटी, बहुत तेज़ मेमोरी जो अभी चल रहे डेटा को पकड़े रहती है।

CPU की गति GHz में मापी जाती है। आज के प्रोसेसर में कई cores होते हैं — dual, quad, octa। ज़्यादा cores का मतलब है कि एक साथ कई काम संभाले जा सकते हैं, पर सिर्फ़ core संख्या देखकर खरीदना ठीक नहीं; generation और cache भी देखें।

2. Motherboard — सबको जोड़ने वाला बोर्ड

Motherboard एक सर्किट बोर्ड है जिस पर CPU, RAM, स्टोरेज और कार्ड लगते हैं। इसमें chipset होता है जो डेटा का रास्ता तय करता है, BIOS/UEFI चिप होती है जो बूटिंग की शुरुआत करती है, और कई slots/ports होते हैं। यही तय करता है कि आप कौन सा प्रोसेसर और कितनी RAM लगा सकते हैं — इसलिए अपग्रेड की सोच रहे हों तो पहले motherboard की सीमा देखें।

3. RAM — अस्थायी काम की मेमोरी

Random Access Memory में वह डेटा रहता है जो अभी इस्तेमाल हो रहा है — खुले ऐप, ब्राउज़र के टैब, चल रहा वीडियो। यह volatile है: बिजली बंद होते ही खाली हो जाती है। RAM ज़्यादा होने से कंप्यूटर कई ऐप एक साथ आसानी से चला पाता है; कम होने पर सिस्टम डिस्क का सहारा लेता है और धीमा हो जाता है। आज 8 GB न्यूनतम और 16 GB आरामदायक माना जाता है।

4. ROM — स्थायी शुरुआती निर्देश

Read Only Memory में वे निर्देश होते हैं जिनकी मदद से कंप्यूटर चालू होते ही पहला काम करता है — जैसे POST (Power On Self Test) और बूट लोडर। यह non-volatile है, बिजली जाने पर भी बना रहता है। आज इसे flash memory में रखा जाता है, जिसे ज़रूरत पड़ने पर update किया जा सकता है।

5. Storage — हार्ड डिस्क और SSD

यहाँ आपकी फ़ाइलें, फोटो, वीडियो और विंडोज़ हमेशा के लिए रहते हैं। HDD में घूमने वाली प्लेटर होती है — सस्ती और बड़ी क्षमता, पर धीमी। SSD में फ्लैश चिप होती है — कई गुना तेज़, हल्की, बिना आवाज़, पर थोड़ी महँगी। पुराने लैपटॉप को SSD लगाने से सबसे बड़ा speed boost मिलता है, यह अनुभव से कहा जा सकता है।

6. Power Supply और कूलिंग

PSU (Power Supply Unit) बिजली को सही वोल्टेज में बदलकर हर हिस्से तक पहुँचाती है। ग़लत या सस्ता PSU पूरे सिस्टम को नुक़सान पहुँचा सकता है। Heat sink और fan CPU व केस को ठंडा रखते हैं; धूल जमने पर कंप्यूटर गरम होकर धीमा हो जाता है, इसलिए साल में एक बार सफ़ाई ज़रूरी है।

7. Ports और कनेक्टर

Portकिसके लिए
USBपेन ड्राइव, माउस, कीबोर्ड, प्रिंटर, फोन चार्जिंग
HDMI / DisplayPortमॉनिटर, प्रोजेक्टर, TV
Ethernet (LAN)वायर वाला इंटरनेट
Audio jackहेडफ़ोन, माइक, स्पीकर
VGA (पुराना)पुराने मॉनिटर/प्रोजेक्टर
एक नज़र में
  • CPU = सोच और गणना
  • Motherboard = सबको जोड़ने वाला बोर्ड
  • RAM = अस्थायी, तेज़, बिजली जाने पर खाली
  • ROM = स्थायी शुरुआती निर्देश
  • HDD/SSD = पक्का स्टोरेज
  • PSU + Fan = बिजली और ठंडक

आगे क्या

हार्डवेयर के बाद सॉफ्टवेयर की बारी है — ऑपरेटिंग सिस्टम और ऐप्स, जो इस लोहे-प्लास्टिक के ढाँचे को काम करने लायक बनाते हैं। अगले लेसन में system software और application software का फ़र्क़ साफ़ हो जाएगा।

Practical — 10 मिनट

Windows में Ctrl + Shift + Esc दबाकर Task Manager खोलें, फिर Performance टैब में CPU, Memory और Disk का इस्तेमाल देखें। साथ में एक भारी ऐप खोलकर देखें कि कौन सा हिस्सा सबसे ज़्यादा बढ़ता है।
