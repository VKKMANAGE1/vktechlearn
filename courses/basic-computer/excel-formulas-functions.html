Chapter 6 · MS Excel के साथ काम

Excel Formulas और Functions — SUM, AVERAGE, IF, COUNT

लेसन 20 / 21·~8 मिनट·by Vïnâý Kúshwâhå

Excel की असली ताक़त उसके फ़ॉर्मूले हैं। एक बार सही फ़ॉर्मूला लिख दें, तो हज़ारों पंक्तियों का हिसाब सेकंडों में हो जाता है — और डेटा बदलते ही नतीजा भी अपने आप बदल जाता है। इस लेसन में फ़ॉर्मूला लिखने का नियम, cell reference और रोज़ काम आने वाले functions देखेंगे।

फ़ॉर्मूला कैसे लिखते हैं

हर फ़ॉर्मूला = से शुरू होता है। जैसे =A1+B1 लिखने पर Excel A1 और B1 के नंबर जोड़ देगा। = के बाद गणित के चिह्न इस्तेमाल होते हैं:

  • + जोड़, - घटाव
  • * गुणा, / भाग
  • ^ घात (power)
  • ( ) पहले हल होने वाला हिस्सा

Cell Reference के तीन प्रकार

प्रकारउदाहरणकॉपी करने पर
RelativeA1नीचे कॉपी करने पर A2, A3… बदलता है
Absolute$A$1हमेशा A1 ही रहता है
MixedA$1 या $A1एक हिस्सा स्थिर, दूसरा बदलता है

उदाहरण: अगर C1 में टैक्स दर 18% है और आप हर पंक्ति में उसी दर से गुणा करना चाहते हैं, तो फ़ॉर्मूला =B2*$C$1 लिखें। वरना नीचे कॉपी करते ही C1 की जगह C2, C3 हो जाएगा और नतीजा गलत आएगा।

रोज़ काम आने वाले Functions

Functionकामउदाहरण
SUMजोड़=SUM(B2:B11)
AVERAGEऔसत=AVERAGE(B2:B11)

IF में और शर्तें

अगर दो से ज़्यादा परिणाम चाहिए तो IF के अंदर IF रखें:

=IF(B2>=80,"A",IF(B2>=60,"B",IF(B2>=33,"C","Fail")))

यह फ़ॉर्मूला पहले 80 से बड़ा देखता है, नहीं तो 60, नहीं तो 33 — वरना Fail। शर्तों का क्रम सबसे सख़्त से सबसे आसान की ओर रखें, वरना गलत नतीजा आ सकता है।

गलतियों के चिह्न

  • #DIV/0! — किसी शून्य से भाग दिया गया।
  • #VALUE! — गलत तरह का डेटा (जैसे टेक्स्ट पर जोड़)।
  • #REF! — संदर्भित cell हट गया।
  • #NAME? — function का नाम गलत लिखा।
  • ##### — कॉलम छोटा है; चौड़ाई बढ़ाएँ।

फ़ॉर्मूला कॉपी और Autofill

फ़ॉर्मूला वाले cell का निचला दायाँ कोना पकड़कर नीचे खींचें — हर पंक्ति के लिए वही फ़ॉर्मूला अपने आप बन जाएगा। दोहरा क्लिक करने पर Excel खुद अंत तक भर देता है। कॉपी करते समय reference का ध्यान रखें; गलत जगह पर $ लगाना या न लगाना सबसे आम गलती है।

याद रखें
  • फ़ॉर्मूला हमेशा = से शुरू होता है
  • $A$1 = absolute, A1 = relative
  • SUM, AVERAGE, IF, COUNT सबसे ज़्यादा काम आते हैं
  • #REF!, #VALUE!, #DIV/0! का मतलब जानें
