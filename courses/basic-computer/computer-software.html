Computer Software — System Software और Application Software

लेसन 5 / 21·~7 मिनट·by Vïnâý Kúshwâhå

हार्डवेयर बिना सॉफ्टवेयर के वैसा ही है जैसा बिना ड्राइवर की गाड़ी — ढाँचा तैयार है, पर चलेगी नहीं। सॉफ्टवेयर निर्देशों का वह समूह है जो कंप्यूटर को बताता है कि क्या करना है और कैसे करना है। इस लेसन में सॉफ्टवेयर के दो बड़े प्रकार, ऑपरेटिंग सिस्टम का काम और आम उदाहरण देखेंगे।

सॉफ्टवेयर के दो मुख्य प्रकार

1. System Software

यह कंप्यूटर को चलाने और हार्डवेयर को संभालने का काम करता है। इसके बिना बाकी सॉफ्टवेयर चल ही नहीं सकते। इसमें आते हैं:

  • Operating System: Windows, Linux, macOS, Android, iOS।
  • Device Drivers: प्रिंटर, ग्राफ़िक्स कार्ड, स्कैनर को OS से जोड़ने वाले छोटे प्रोग्राम।
  • Utility Programs: antivirus, disk cleanup, backup, file compression, task manager।
  • Language Translators: compiler, interpreter, assembler — जो प्रोग्रामिंग भाषा को मशीन भाषा में बदलते हैं।

2. Application Software

यह यूज़र के किसी खास काम के लिए बनाया जाता है — लिखना, हिसाब, डिज़ाइन, वीडियो एडिटिंग, गेम या ब्राउज़िंग। उदाहरण: MS Word, Excel, PowerPoint, Chrome, WhatsApp, Photoshop, Tally, कैलकुलेटर और बैंकिंग ऐप।

Application software को दो तरह से भी बाँटा जाता है — readymade (package) जैसे MS Office, जिसे सीधे खरीदकर इस्तेमाल करते हैं, और custom software जो किसी दुकान, अस्पताल या कंपनी की अपनी ज़रूरत के हिसाब से बनवाया जाता है।

ऑपरेटिंग सिस्टम का काम

Operating System कंप्यूटर का मास्टर कंट्रोल प्रोग्राम है। ट्रैफ़िक पुलिस की तरह यह तय करता है कि कौन सा प्रोग्राम कब और कितनी जगह लेगा। इसके मुख्य काम:

  • Process Management: कौन सा प्रोग्राम कब चलेगा, यह तय करना।
  • Memory Management: RAM को अलग-अलग प्रोग्राम में बाँटना।
  • File Management: फ़ाइलें और फ़ोल्डर बनाना, नाम बदलना, सेव करना।
  • Device Management: प्रिंटर, माउस, कैमरा जैसे डिवाइस चलाना।
  • Security: यूज़र अकाउंट, पासवर्ड और permission संभालना।
  • User Interface: GUI (आइकन, विंडो) या command line उपलब्ध कराना।

सॉफ्टवेयर के कुछ और प्रकार

प्रकारकामउदाहरण
Utility softwareसिस्टम साफ़ और सुरक्षित रखनाAntivirus, Disk Cleanup, WinRAR
Firmwareहार्डवेयर के अंदर लिखा स्थायी प्रोग्रामRouter का firmware, BIOS
Programming softwareनए प्रोग्राम बनानाPython IDLE, VS Code, compiler
Open source softwareसोर्स कोड सबके लिए खुलाLibreOffice, GIMP, Linux, VLC
Proprietary softwareकंपनी का बंद सोर्स, लाइसेंस परMS Office, Photoshop, Windows

लाइसेंस का मतलब क्या है

सॉफ्टवेयर खरीदना का मतलब उसे "मालिक" बनना नहीं होता; आपको उसे इस्तेमाल करने का लाइसेंस मिलता है। एक ही license कई कंप्यूटर पर चलाना नियम तोड़ना है। मुफ़्त में मिलने वाले सॉफ्टवेयर भी दो तरह के होते हैं — freeware (मुफ़्त इस्तेमाल, सोर्स बंद) और open source (कोड खुला, बदलाव की छूट)। साथ में free trial भी मिलता है, जो कुछ दिन बाद बंद हो जाता है।

फ़र्क़ याद रखें
  • System software = कंप्यूटर चलाता है
  • Application software = यूज़र का काम करता है
  • Windows/Linux = OS; Word/Excel = application
  • Driver = हार्डवेयर और OS के बीच पुल

आगे क्या

अगला लेसन Windows Desktop का है — यहीं से practical शुरू होता है। Start menu, taskbar, फ़ाइल-फ़ोल्डर, copy-paste और Settings को एक-एक करके चलाकर देखेंगे।

Practical — 5 मिनट

अपने कंप्यूटर पर Settings → Apps (या Installed Apps) खोलें और 5 सॉफ्टवेयर की सूची बनाएँ। हर एक के आगे लिखें — system software या application software।
