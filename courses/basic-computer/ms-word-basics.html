MS Word Basics — Interface, Ribbon और Formatting

लेसन 17 / 21·~8 मिनट·by Vïnâý Kúshwâhå

MS Word दुनिया का सबसे ज़्यादा इस्तेमाल होने वाला word processor है। आवेदन पत्र, रिज़्यूमे, प्रोजेक्ट रिपोर्ट, नोट्स और बुकlet — सब यहीं बनते हैं। इस लेसन में Word की स्क्रीन, Ribbon, टाइपिंग-फ़ॉर्मेटिंग, page setup, save और print को step-by-step देखेंगे।

नया डॉक्यूमेंट खोलना

  1. Word खोलें और Blank document चुनें।
  2. ऊपर title bar में फ़ाइल का नाम दिखेगा — अभी "Document1"।
  3. पहला काम: Ctrl + S दबाकर नाम और जगह चुनकर सेव करें।

सेव करते समय नाम ऐसा रखें जिससे बाद में पहचाना जाए — जैसे Resume_Rahul_2026.docx। हर 5–10 मिनट में Ctrl + S दबाने की आदत बना लें।

Word की स्क्रीन

  • Title bar: सबसे ऊपर — फ़ाइल का नाम और Minimize/Maximize/Close बटन।
  • Quick Access Toolbar: Save, Undo, Redo जैसे छोटे बटन।
  • Ribbon: टैब (Home, Insert, Design, Layout, References, Mailings, Review, View) और उनके command बटन।
  • Ruler: पेज का margin और indent दिखाने वाला पैमाना।
  • Document area: जहाँ टाइपिंग होती है; सफ़ेद पेज।
  • Status bar: नीचे — पेज नंबर, शब्द गिनती, भाषा और zoom।

टाइपिंग और फ़ॉर्मेटिंग

Home टैब में सबसे ज़रूरी बटन होते हैं:

कामबटन/शॉर्टकट
BoldCtrl + B
ItalicCtrl + I
UnderlineCtrl + U
Font और sizeHome → Font group
AlignmentLeft, Center, Right, Justify
Bullets/NumberingHome → Paragraph group
Copy / PasteCtrl + C / Ctrl + V
FindCtrl + F

फ़ॉर्मेटिंग का सुनहरा नियम: पूरे डॉक्यूमेंट में एक जैसा font रखें (जैसे English के लिए Calibri या Arial), heading के लिए बड़ा size और bold, और body के लिए 11–12 pt। ज़्यादा रंग और अलग-अलग font से डॉक्यूमेंट अनप्रोफेशनल लगता है।

Heading और Styles

Styles का इस्तेमाल करने से document को structure मिलता है और बाद में Table of Contents अपने आप बन जाता है। Heading 1, Heading 2, Normal — इन्हें Home टैब के Styles group से लगाएँ। रिपोर्ट या प्रोजेक्ट बनाते समय यह तरीका समय बचाता है।

Page Setup

Layout टैब में Margins, Orientation (Portrait/Landscape), Size (A4) और Columns मिलते हैं। आम डॉक्यूमेंट के लिए A4, Portrait और 1 इंच margin ठीक रहता है। Insert टैब से Page Break, Page Number, Header/Footer, Table, Picture और Shapes जोड़े जा सकते हैं।

सेव और प्रिंट

Save (Ctrl + S) फ़ाइल को उसी नाम से अपडेट करता है; Save As (F12) नई copy बनाता है। प्रिंट से पहले Ctrl + P से preview देखें — कहीं पेज बीच में न कट रहा हो। अगर किसी दूसरे कंप्यूटर पर भेजना है और फ़ॉर्मेटिंग बिगड़ने का डर है, तो PDF में सेव करें (File → Save As → PDF)।

ज़रूरी शॉर्टकट
  • Ctrl + S — Save
  • Ctrl + P — Print
  • Ctrl + Z — Undo, Ctrl + Y — Redo
  • Ctrl + F — Find, Ctrl + H — Replace
  • Ctrl + Enter — नया पेज

आम गलतियाँ

  • बार-बार Enter दबाकर नया पेज बनाना — इसके लिए Page Break (Ctrl + Enter) सही है।
  • Space देकर टेबल बनाना — Insert → Table इस्तेमाल करें।
  • फ़ाइल सेव न करना और बिजली जाने पर काम गँवाना — AutoSave और Ctrl + S दोनों रखें।

आगे क्या

अगला लेसन PowerPoint का है — स्लाइड बनाना, design, transition और presentation देने का तरीका।

Practical — 10 मिनट

Word में एक पेज का परिचय पत्र बनाएँ: नाम Heading 1 में, पता और संपर्क नीचे, फिर एक बुलेट लिस्ट में अपनी तीन खूबियाँ। Ctrl + S से सेव करें और PDF में भी निकालें।
