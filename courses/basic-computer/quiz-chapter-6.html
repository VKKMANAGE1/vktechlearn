Chapter 6 · MS Excel के साथ काम

Chapter 6 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

हर सवाल का एक विकल्प चुनें और नीचे जवाब जमा करें दबाएँ — स्कोर और हर सवाल की व्याख्या तुरंत दिखेगी। 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. Excel की पूरी फ़ाइल को क्या कहते हैं?

    सही उत्तर: Workbook — Workbook पूरी .xlsx फ़ाइल है, जिसमें कई worksheets (sheets) हो सकती हैं।

  2. Cell का पता किस प्रकार लिखा जाता है?

    सही उत्तर: कॉलम + पंक्ति, जैसे A1 — कॉलम पहले (A, B, C) और पंक्ति बाद में (1, 2, 3) — इसलिए A1, B2 आदि।

  3. Excel में फ़ॉर्मूला किस चिह्न से शुरू होता है?

    सही उत्तर: = — हर फ़ॉर्मूला = से शुरू होता है, जैसे =A1+B1।

  4. गुणा करने के लिए Excel में कौन सा चिह्न इस्तेमाल होता है?

    सही उत्तर: * — Excel में * गुणा, / भाग, ^ घात और - घटाव के लिए है।

  5. A1 किस प्रकार का reference है?

    सही उत्तर: Relative — A1 relative है — नीचे कॉपी करने पर A2, A3 हो जाता है।

  6. $A$1 किस प्रकार का reference है?

    सही उत्तर: Absolute — $A$1 absolute है, कॉपी करने पर भी वही रहता है।

  7. SUM function का सही उदाहरण कौन सा है?

    सही उत्तर: =SUM(B2:B11) — SUM रेंज का जोड़ निकालता है; =SUM(B2:B11) सही तरीका है।

  8. औसत निकालने के लिए कौन सा function है?

    सही उत्तर: AVERAGE — Excel में औसत के लिए AVERAGE function है।

  9. =IF(B2>=33,"Pass","Fail") क्या करेगा?

    सही उत्तर: 33 या ज़्यादा होने पर Pass देगा — शर्त सही होने पर पहला मान (Pass), गलत होने पर दूसरा (Fail) आता है।

  10. किस function से पता चलता है कि रेंज में कितने नंबर हैं?

    सही उत्तर: COUNT — COUNT सिर्फ़ नंबर गिनता है; COUNTA खाली सेल छोड़कर सब भरे सेल गिनता है।

  11. #DIV/0! का मतलब क्या है?

    सही उत्तर: शून्य से भाग दिया गया — किसी सेल को 0 से भाग देने पर #DIV/0! आता है; IFERROR से संभाल सकते हैं।

  12. ##### क्यों दिखता है?

    सही उत्तर: कॉलम छोटा है — नंबर कॉलम में फ़िट नहीं होता, इसलिए कॉलम की चौड़ाई बढ़ानी पड़ती है।

  13. Fill handle से क्या होता है?

    सही उत्तर: फ़ॉर्मूला या सीरीज़ नीचे कॉपी होती है — सेल के निचले दाएँ कोने को खींचने पर सीरीज़ या फ़ॉर्मूला अपने आप भर जाता है।

  14. Filter करने पर डेटा क्या होता है?

    सही उत्तर: छिप जाता है, बाद में वापस दिख सकता है — Filter सिर्फ़ दिखने वाली पंक्तियाँ बदलता है; Clear करने पर डेटा वापस दिख जाता है।

  15. VLOOKUP में table_array को $ से fix करने की ज़रूरत क्यों होती है?

    सही उत्तर: ताकि नीचे कॉपी करने पर रेंज न बदले — Absolute reference से रेंज हर पंक्ति में वही रहती है, वरना नतीजा गलत आ सकता है।

  16. VLOOKUP में col_index क्या बताता है?

    सही उत्तर: कौन सा कॉलम — col_index उस table में कॉलम की गिनती है (1 से शुरू) जिससे जानकारी लेनी है।

  17. VLOOKUP में सटीक मिलान के लिए क्या लिखते हैं?

    सही उत्तर: FALSE या 0 — range_lookup में FALSE (या 0) लिखने पर सटीक मिलान होता है।

  18. किस चार्ट से बदलाव या ट्रेंड सबसे अच्छा दिखता है?

    सही उत्तर: Line — Line चार्ट समय के साथ बदलाव दिखाता है; Pie हिस्सेदारी और Column तुलना के लिए है।

  19. Pivot Table का सबसे बड़ा फ़ायदा क्या है?

    सही उत्तर: बिना फ़ॉर्मूला बड़े डेटा का सारांश — Pivot Table क्षेत्र, महीने या श्रेणी के हिसाब से सारांश कुछ क्लिक में बना देता है।

  20. Pivot Table में Values बॉक्स में क्या रखते हैं?

    सही उत्तर: जिस संख्या का सारांश चाहिए — Values में वह संख्या डालते हैं जिसका Sum, Count या Average चाहिए।
