Chapter 6 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

हर सवाल के चार विकल्प हैं। पहले सारे 20 के जवाब कागज़ पर लिखें, फिर नीचे उत्तर-कुंजी से जाँचें — 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. Excel की पूरी फ़ाइल को क्या कहते हैं?

    1. Worksheet
    2. Workbook
    3. Cell
    4. Range

  2. Cell का पता किस प्रकार लिखा जाता है?

    1. पंक्ति + कॉलम, जैसे 1A
    2. कॉलम + पंक्ति, जैसे A1
    3. सिर्फ़ नंबर
    4. सिर्फ़ अक्षर

  3. Excel में फ़ॉर्मूला किस चिह्न से शुरू होता है?

    1. +
    2. =
    3. @
    4. #

  4. गुणा करने के लिए Excel में कौन सा चिह्न इस्तेमाल होता है?

    1. x
    2. *
    3. ·
    4. ×

  5. A1 किस प्रकार का reference है?

    1. Relative
    2. Absolute
    3. Mixed
    4. External

  6. $A$1 किस प्रकार का reference है?

    1. Relative
    2. Absolute
    3. Mixed
    4. कोई नहीं

  7. SUM function का सही उदाहरण कौन सा है?

    1. =SUM(B2:B11)
    2. =ADD(B2:B11)
    3. =TOTAL(B2:B11)
    4. =PLUS(B2:B11)

  8. औसत निकालने के लिए कौन सा function है?

    1. MEAN
    2. AVERAGE
    3. MID
    4. AVG

  9. =IF(B2>=33,"Pass","Fail") क्या करेगा?

    1. 33 से कम होने पर Pass देगा
    2. 33 या ज़्यादा होने पर Pass देगा
    3. हमेशा Fail देगा
    4. गड़बड़ी दिखाएगा

  10. किस function से पता चलता है कि रेंज में कितने नंबर हैं?

    1. COUNT
    2. COUNTA
    3. SUM
    4. LEN

  11. #DIV/0! का मतलब क्या है?

    1. शून्य से भाग दिया गया
    2. फ़ाइल नहीं मिली
    3. कॉलम छोटा है
    4. नाम गलत है

  12. ##### क्यों दिखता है?

    1. कॉलम छोटा है
    2. फ़ॉर्मूला गलत है
    3. फ़ाइल खराब है
    4. इंटरनेट बंद है

  13. Fill handle से क्या होता है?

    1. फ़ॉर्मूला या सीरीज़ नीचे कॉपी होती है
    2. फ़ाइल सेव होती है
    3. शीट डिलीट होती है
    4. प्रिंटर चलता है

  14. Filter करने पर डेटा क्या होता है?

    1. हट जाता है
    2. छिप जाता है, बाद में वापस दिख सकता है
    3. प्रिंट हो जाता है
    4. दूसरी शीट में चला जाता है

  15. VLOOKUP में table_array को $ से fix करने की ज़रूरत क्यों होती है?

    1. ताकि नीचे कॉपी करने पर रेंज न बदले
    2. ताकि फ़ाइल छोटी हो
    3. ताकि रंग बदले
    4. ताकि प्रिंट हो

  16. VLOOKUP में col_index क्या बताता है?

    1. कौन सा कॉलम
    2. कौन सी पंक्ति
    3. कितने पेज
    4. कौन सी शीट

  17. VLOOKUP में सटीक मिलान के लिए क्या लिखते हैं?

    1. TRUE
    2. FALSE या 0
    3. 1
    4. कुछ नहीं

  18. किस चार्ट से बदलाव या ट्रेंड सबसे अच्छा दिखता है?

    1. Pie
    2. Line
    3. Column
    4. Bar

  19. Pivot Table का सबसे बड़ा फ़ायदा क्या है?

    1. बिना फ़ॉर्मूला बड़े डेटा का सारांश
    2. फ़ाइल कंप्रेस करना
    3. प्रिंटर चलाना
    4. ईमेल भेजना

  20. Pivot Table में Values बॉक्स में क्या रखते हैं?

    1. जिस संख्या का सारांश चाहिए
    2. सिर्फ़ तारीख
    3. सिर्फ़ नाम
    4. चार्ट

उत्तर-कुंजी

  1. Q1 — (b) Workbook
    Workbook पूरी .xlsx फ़ाइल है, जिसमें कई worksheets (sheets) हो सकती हैं।
  2. Q2 — (b) कॉलम + पंक्ति, जैसे A1
    कॉलम पहले (A, B, C) और पंक्ति बाद में (1, 2, 3) — इसलिए A1, B2 आदि।
  3. Q3 — (b) =
    हर फ़ॉर्मूला = से शुरू होता है, जैसे =A1+B1।
  4. Q4 — (b) *
    Excel में * गुणा, / भाग, ^ घात और - घटाव के लिए है।
  5. Q5 — (a) Relative
    A1 relative है — नीचे कॉपी करने पर A2, A3 हो जाता है।
  6. Q6 — (b) Absolute
    $A$1 absolute है, कॉपी करने पर भी वही रहता है।
  7. Q7 — (a) =SUM(B2:B11)
    SUM रेंज का जोड़ निकालता है; =SUM(B2:B11) सही तरीका है।
  8. Q8 — (b) AVERAGE
    Excel में औसत के लिए AVERAGE function है।
  9. Q9 — (b) 33 या ज़्यादा होने पर Pass देगा
    शर्त सही होने पर पहला मान (Pass), गलत होने पर दूसरा (Fail) आता है।
  10. Q10 — (a) COUNT
    COUNT सिर्फ़ नंबर गिनता है; COUNTA खाली सेल छोड़कर सब भरे सेल गिनता है।
  11. Q11 — (a) शून्य से भाग दिया गया
    किसी सेल को 0 से भाग देने पर #DIV/0! आता है; IFERROR से संभाल सकते हैं।
  12. Q12 — (a) कॉलम छोटा है
    नंबर कॉलम में फ़िट नहीं होता, इसलिए कॉलम की चौड़ाई बढ़ानी पड़ती है।
  13. Q13 — (a) फ़ॉर्मूला या सीरीज़ नीचे कॉपी होती है
    सेल के निचले दाएँ कोने को खींचने पर सीरीज़ या फ़ॉर्मूला अपने आप भर जाता है।
  14. Q14 — (b) छिप जाता है, बाद में वापस दिख सकता है
    Filter सिर्फ़ दिखने वाली पंक्तियाँ बदलता है; Clear करने पर डेटा वापस दिख जाता है।
  15. Q15 — (a) ताकि नीचे कॉपी करने पर रेंज न बदले
    Absolute reference से रेंज हर पंक्ति में वही रहती है, वरना नतीजा गलत आ सकता है।
  16. Q16 — (a) कौन सा कॉलम
    col_index उस table में कॉलम की गिनती है (1 से शुरू) जिससे जानकारी लेनी है।
  17. Q17 — (b) FALSE या 0
    range_lookup में FALSE (या 0) लिखने पर सटीक मिलान होता है।
  18. Q18 — (b) Line
    Line चार्ट समय के साथ बदलाव दिखाता है; Pie हिस्सेदारी और Column तुलना के लिए है।
  19. Q19 — (a) बिना फ़ॉर्मूला बड़े डेटा का सारांश
    Pivot Table क्षेत्र, महीने या श्रेणी के हिसाब से सारांश कुछ क्लिक में बना देता है।
  20. Q20 — (a) जिस संख्या का सारांश चाहिए
    Values में वह संख्या डालते हैं जिसका Sum, Count या Average चाहिए।
