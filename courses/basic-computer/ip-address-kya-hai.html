IP Address क्या है? IPv4, IPv6, Public और Private IP

लेसन 12 / 21·~7 मिनट·by Vïnâý Kúshwâhå

नेटवर्क में हर डिवाइस को एक पता चाहिए, वरना डेटा किसे भेजा जाए यह पता नहीं चलेगा। इसी पते को IP address कहते हैं। यह घर के पते जैसा है — जितना सही पता, उतनी ही तेज़ी से चिट्ठी पहुँचती है।

IP address क्या है

IP का पूरा नाम Internet Protocol address है। यह अंकों की एक श्रृंखला होती है जो नेटवर्क में डिवाइस की पहचान बताती है और यह भी तय करती है कि उसका नेटवर्क कौन सा है।

IPv4 और IPv6

  • IPv4: 32-bit पता, चार भागों में लिखा जाता है — जैसे 192.168.1.10। हर भाग 0 से 255 तक होता है। कुल पते लगभग 4.3 अरब हैं, जो कम पड़ गए।
  • IPv6: 128-bit पता, आठ भागों में हेक्साडेसिमल रूप में — जैसे 2001:0db8:85a3::8a2e:0370:7334। इसमें पते की संख्या इतनी बड़ी है कि लगभग खत्म नहीं हो सकती।

Public IP और Private IP

Public IPPrivate IP
इंटरनेट पर दिखता है, ISP देता हैघर/दफ़्तर के अंदर इस्तेमाल होता है, router देता है
पूरी दुनिया में uniqueहर नेटवर्क में दोहराया जा सकता है
वेबसाइट और सर्वर से सीधे जुड़ता हैआमतौर पर 192.168.x.x, 10.x.x.x, 172.16–31.x.x

आपके फोन का IP 192.168.1.5 हो सकता है, पर इंटरनेट पर आप router के public IP से दिखते हैं। इस बदलाव को NAT (Network Address Translation) कहते हैं — router कई private डिवाइस को एक public IP से बाहर भेजता है।

Static और Dynamic IP

Static IP हर बार वही रहता है — सर्वर, प्रिंटर या CCTV के लिए अच्छा। Dynamic IP router से अपने आप मिलता है और कुछ समय बाद बदल सकता है; घर के डिवाइस आमतौर पर इसी पर चलते हैं। इसे DHCP सेवा संभालती है।

अपना IP कैसे देखें

  • Windows: Command Prompt में ipconfig चलाएँ — IPv4 Address दिखेगा।
  • मोबाइल: Settings → Wi-Fi → जुड़े नेटवर्क पर टैप → IP address।
  • Public IP: ब्राउज़र में "what is my ip" खोजें, या router के admin page में WAN address देखें।

IP और DNS का रिश्ता

इंसान नाम याद रखता है, कंप्यूटर नंबर। जब आप google.com लिखते हैं, तो DNS (Domain Name System) उसे IP address में बदल देता है। DNS इंटरनेट की फ़ोन बुक है। अगर DNS काम न करे, तो इंटरनेट चलते हुए भी साइटें नहीं खुलेंगी — ऐसे में DNS बदलकर (जैसे 8.8.8.8) आज़माना काम आता है।

याद रखें
  • IP = नेटवर्क में डिवाइस का पता
  • IPv4 = 32-bit, IPv6 = 128-bit
  • Private IP घर के अंदर, Public IP इंटरनेट पर
  • DNS नाम को IP में बदलता है

आगे क्या

अब चैप्टर 4 — Internet Basics शुरू। इंटरनेट कैसे बना, ISP क्या करता है, WWW का मतलब क्या है और HTTP, FTP जैसे protocols कैसे काम करते हैं, यह अगले लेसन में देखेंगे।

Practical — 5 मिनट

Command Prompt या मोबाइल की सेटिंग में अपना private IP देखें, फिर ब्राउज़र में अपना public IP खोजें। दोनों अलग क्यों हैं — एक लाइन में लिखें।
