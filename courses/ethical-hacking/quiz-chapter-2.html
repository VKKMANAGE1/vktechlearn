Chapter 2 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

हर सवाल का एक विकल्प चुनें और नीचे जवाब जमा करें दबाएँ — स्कोर और हर सवाल की व्याख्या तुरंत दिखेगी। 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. Python में string क्या है?

    सही उत्तर: Text वाली value — IP, URL और नाम string में रखे जाते हैं।

  2. Python में integer type किसके लिए है?

    सही उत्तर: पूर्ण संख्या — Port और count जैसी पूर्ण संख्याएँ integer होती हैं।

  3. Python में if का काम क्या है?

    सही उत्तर: शर्त के हिसाब से code चलाना — if/elif/else से शर्त के अनुसार अलग code चलता है।

  4. for loop किस पर चलता है?

    सही उत्तर: सूची या range पर — for loop list, string, range जैसी चीज़ों पर एक-एक करके चलता है।

  5. function बनाने का सही तरीका कौन सा है?

    सही उत्तर: def check(): — Python में function def से बनता है।

  6. function का फ़ायदा क्या है?

    सही उत्तर: Code दोबारा लिखने से बचता है — एक बार लिखा function कई जगह बुलाया जा सकता है।

  7. dictionary किस तरह का data रखती है?

    सही उत्तर: key-value जोड़े — Result को {"host": ..., "port": ...} जैसे जोड़ों में रखा जाता है।

  8. try/except का मक़सद क्या है?

    सही उत्तर: Error आने पर script को संभालना — एक host fail होने पर पूरा script नहीं रुकता।

  9. socket library किसके लिए इस्तेमाल होती है?

    सही उत्तर: Network connection बनाना — socket से TCP connection और port check होता है।

  10. requests library क्या करती है?

    सही उत्तर: HTTP request भेजना — requests से GET/POST भेजकर response देखा जाता है।

  11. hashlib किसके लिए है?

    सही उत्तर: Hash बनाना — hashlib से MD5/SHA-256 जैसे hash बनते हैं।

  12. Python में टिप्पणी (comment) कैसे लिखते हैं?

    सही उत्तर: # से — Python में # के बाद की पंक्ति comment होती है।

  13. print() का काम क्या है?

    सही उत्तर: Output दिखाना — print से terminal पर result दिखता है।

  14. Port list पर loop चलाकर हम क्या कर सकते हैं?

    सही उत्तर: हर port की जाँच — Loop से एक-एक port check होता है।

  15. list में तीसरा element किस index पर होता है?

    सही उत्तर: 2 — Python में index 0 से शुरू होता है, इसलिए तीसरा element index 2 पर है।

  16. len() function क्या बताता है?

    सही उत्तर: लंबाई या तत्वों की संख्या — len() string या list का आकार बताता है।

  17. argparse किस काम आता है?

    सही उत्तर: Command-line arguments पढ़ने के लिए — argparse से script को options दिए जाते हैं।

  18. Python में indentation क्यों ज़रूरी है?

    सही उत्तर: Code block की पहचान के लिए — Python में spaces से ही block तय होता है।

  19. किसी function को कॉल कैसे करते हैं?

    सही उत्तर: check_host() — नाम के बाद कोष्ठक लगाकर function चलता है।

  20. Script में result सेव करने का सबसे अच्छा तरीका क्या है?

    सही उत्तर: JSON या CSV में — JSON/CSV से बाद में report और analysis आसान होता है।
