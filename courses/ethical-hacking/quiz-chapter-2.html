पहले सारे 20 के जवाब कागज़ पर लिखें, फिर नीचे उत्तर-कुंजी से जाँचें — 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. Python में string क्या है?

    1. Text वाली value
    2. सिर्फ़ संख्या
    3. एक loop
    4. एक file

  2. Python में integer type किसके लिए है?

    1. पूर्ण संख्या
    2. दशमलव संख्या
    3. text
    4. boolean

  3. Python में if का काम क्या है?

    1. शर्त के हिसाब से code चलाना
    2. loop चलाना
    3. file सेव करना
    4. error दिखाना

  4. for loop किस पर चलता है?

    1. सूची या range पर
    2. सिर्फ़ संख्या पर
    3. सिर्फ़ file पर
    4. सिर्फ़ string पर

  5. function बनाने का सही तरीका कौन सा है?

    1. def check():
    2. function check():
    3. func check():
    4. def check[]

    1. Code दोबारा लिखने से बचता है

  7. dictionary किस तरह का data रखती है?

    1. key-value जोड़े
    2. सिर्फ़ संख्याएँ
    3. सिर्फ़ अक्षर
    4. सिर्फ़ फ़ाइलें

  8. try/except का मक़सद क्या है?

    1. Error आने पर script को संभालना
    2. Loop रोकना
    3. फ़ाइल बनाना
    4. Print करना

  9. socket library किसके लिए इस्तेमाल होती है?

    1. Network connection बनाना
    2. Image बनाना
    3. Excel खोलना
    4. PDF पढ़ना

    1. HTTP request भेजना
    2. File delete करना

    4. Password बनाना

    1. Hash बनाना
    2. Loop चलाना
    3. File खोलना
    4. Chart बनाना

  12. Python में टिप्पणी (comment) कैसे लिखते हैं?

    1. # से
    2. // से

उत्तर-कुंजी

  1. Q1 — (a) Text वाली value
    IP, URL और नाम string में रखे जाते हैं।
  2. Q2 — (a) पूर्ण संख्या
    Port और count जैसी पूर्ण संख्याएँ integer होती हैं।
  3. Q3 — (a) शर्त के हिसाब से code चलाना
    if/elif/else से शर्त के अनुसार अलग code चलता है।
  4. Q4 — (a) सूची या range पर
    for loop list, string, range जैसी चीज़ों पर एक-एक करके चलता है।
  5. Q5 — (a) def check():
    Python में function def से बनता है।
  6. Q6 — (a) Code दोबारा लिखने से बचता है
    एक बार लिखा function कई जगह बुलाया जा सकता है।
  7. Q7 — (a) key-value जोड़े
    Result को {"host": ..., "port": ...} जैसे जोड़ों में रखा जाता है।
  8. Q8 — (a) Error आने पर script को संभालना
    एक host fail होने पर पूरा script नहीं रुकता।
  9. Q9 — (a) Network connection बनाना
    socket से TCP connection और port check होता है।
  10. Q10 — (a) HTTP request भेजना
    requests से GET/POST भेजकर response देखा जाता है।
  11. Q11 — (a) Hash बनाना
    hashlib से MD5/SHA-256 जैसे hash बनते हैं।
  12. Q12 — (a) # से
    Python में # के बाद की पंक्ति comment होती है।
  13. Q13 — (a) Output दिखाना
    print से terminal पर result दिखता है।
  14. Q14 — (a) हर port की जाँच
    Loop से एक-एक port check होता है।
  15. Q15 — (a) 2
    Python में index 0 से शुरू होता है, इसलिए तीसरा element index 2 पर है।
  16. Q16 — (a) लंबाई या तत्वों की संख्या
    len() string या list का आकार बताता है।
  17. Q17 — (a) Command-line arguments पढ़ने के लिए
    argparse से script को options दिए जाते हैं।
  18. Q18 — (a) Code block की पहचान के लिए
    Python में spaces से ही block तय होता है।
  19. Q19 — (a) check_host()
    नाम के बाद कोष्ठक लगाकर function चलता है।
  20. Q20 — (a) JSON या CSV में
    JSON/CSV से बाद में report और analysis आसान होता है।
