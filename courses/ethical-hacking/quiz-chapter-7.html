Chapter 7 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

पहले सारे 20 के जवाब कागज़ पर लिखें, फिर नीचे उत्तर-कुंजी से जाँचें — 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. IDS का मुख्य काम क्या है?

    1. संदिग्ध गतिविधि पर alert देना
    2. हमला रोकना
    3. Password बदलना
    4. Backup लेना

  2. HIDS क्या देखता है?

    1. एक host की files, logs और processes
    2. सिर्फ़ network traffic
    3. सिर्फ़ Wi-Fi
    4. सिर्फ़ printers

  3. Signature-based detection की कमी क्या है?

    1. नए अनजान हमले छूट सकते हैं
    2. बहुत धीमा
    3. कभी काम नहीं करता
    4. सिर्फ़ Linux में चलता है

  4. Anomaly-based detection किस पर आधारित है?

    1. सामान्य व्यवहार से हटने पर
    2. ज्ञात signature पर
    3. File size पर
    4. Password length पर

  5. False positive कम करने का तरीका क्या है?

    1. Threshold और allowlist
    2. सारे alerts बंद
    3. IDS हटाना
    4. Logging बंद

  6. Linux में failed logins किस log में मिलते हैं?

    1. /var/log/auth.log
    2. /etc/passwd
    3. /var/www
    4. /home

  7. File integrity monitoring में क्या तुलना होती है?

    1. फ़ाइल के hash की
    2. फ़ाइल के रंग की
    3. फ़ाइल के नाम की
    4. फ़ोल्डर के आइकन की

  8. Hardening का मतलब क्या है?

    1. Attack surface छोटा करना
    2. सारे ports खोलना
    3. Antivirus हटाना
    4. Password साझा करना

  9. Least privilege का सिद्धांत क्या है?

    1. सिर्फ़ ज़रूरी अधिकार देना
    2. सबको admin बनाना
    3. कोई अधिकार न देना
    4. सबको एक password

  10. Firewall की सही नीति क्या है?

    1. Default deny, ज़रूरी ही allow
    2. Default allow
    3. सब खुला
    4. Firewall बंद

  11. 3-2-1 backup नियम क्या है?

    1. 3 copy, 2 माध्यम, 1 offline
    2. 3 servers, 2 users, 1 password
    3. 3 दिन, 2 घंटे, 1 फ़ाइल
    4. 3 antivirus, 2 firewall, 1 VPN

  12. Incident response का पहला चरण क्या है?

    1. Preparation
    2. Containment
    3. Eradication
    4. Recovery

  13. Containment में क्या किया जाता है?

    1. असर फैलने से रोकना
    2. Malware हटाना
    3. Report लिखना
    4. Backup बनाना

  14. Forensic evidence में सबसे पहले क्या सुरक्षित करें?

    1. Volatile data — processes, connections
    2. Disk की सारी files
    3. Printer
    4. Keyboard

  15. psutil library किसके लिए है?

    1. Processes और system जानकारी
    2. PDF बनाना
    3. Image edit
    4. Video

  16. Logging का फ़ायदा क्या है?

    1. घटनाओं का रिकॉर्ड और investigation
    2. Speed बढ़ती है
    3. Password बदलता है
    4. Wi-Fi बढ़ता है

  17. Patch management क्यों ज़रूरी है?

    1. Known कमज़ोरियाँ बंद होती हैं
    2. रंग बदलते हैं
    3. File छोटी होती है
    4. Printer चलता है

  18. Incident के बाद lessons learned का मक़सद क्या है?

    1. दोबारा न हो, इसके लिए सुधार
    2. दोषी ढूँढना
    3. Report छिपाना
    4. Backup मिटाना

  19. अनचाहा खुला port क्या दर्शाता है?

    1. अनजाना attack surface
    2. अच्छी सुरक्षा
    3. तेज़ internet
    4. कोई मतलब नहीं

  20. Defense में सबसे कमज़ोर कड़ी अक्सर क्या होती है?

    1. इंसान और process
    2. Hardware
    3. Cable
    4. Monitor

उत्तर-कुंजी

  1. Q1 — (a) संदिग्ध गतिविधि पर alert देना
    IDS detect करता है; रोकना IPS का काम है।
  2. Q2 — (a) एक host की files, logs और processes
    Host-based IDS एक मशीन की गतिविधि पर नज़र रखता है।
  3. Q3 — (a) नए अनजान हमले छूट सकते हैं
    ज्ञात patterns से मिलान होता है, इसलिए नए हमले बच सकते हैं।
  4. Q4 — (a) सामान्य व्यवहार से हटने पर
    Baseline से अलग गतिविधि पर alert आता है।
  5. Q5 — (a) Threshold और allowlist
    बार-बार होने पर alert और ज्ञात अच्छे IP allowlist करने से शोर कम होता है।
  6. Q6 — (a) /var/log/auth.log
    auth.log में authentication की घटनाएँ दर्ज होती हैं।
  7. Q7 — (a) फ़ाइल के hash की
    Hash बदलने का मतलब फ़ाइल बदली गई।
  8. Q8 — (a) Attack surface छोटा करना
    कम services, updates और least privilege से हमला कठिन होता है।
  9. Q9 — (a) सिर्फ़ ज़रूरी अधिकार देना
    कम अधिकार से गलती या हमले का असर सीमित रहता है।
  10. Q10 — (a) Default deny, ज़रूरी ही allow
    जो ज़रूरी नहीं, उसे बंद रखना सबसे सुरक्षित है।
  11. Q11 — (a) 3 copy, 2 माध्यम, 1 offline
    यह नियम ransomware और hardware failure दोनों से बचाता है।
  12. Q12 — (a) Preparation
    Plan, contacts और tools पहले से तैयार होने चाहिए।
  13. Q13 — (a) असर फैलने से रोकना
    संक्रमित system को अलग करके फैलाव रोका जाता है।
  14. Q14 — (a) Volatile data — processes, connections
    Memory और connections बंद करने पर खो जाते हैं।
  15. Q15 — (a) Processes और system जानकारी
    psutil से चल रहे processes और resources देखे जाते हैं।
  16. Q16 — (a) घटनाओं का रिकॉर्ड और investigation
    Logs से समय के साथ घटनाएँ जोड़ी जा सकती हैं।
  17. Q17 — (a) Known कमज़ोरियाँ बंद होती हैं
    पुराने software की known कमज़ोरियाँ सबसे आम रास्ता हैं।
  18. Q18 — (a) दोबारा न हो, इसके लिए सुधार
    इससे process और controls बेहतर होते हैं।
  19. Q19 — (a) अनजाना attack surface
    हर खुला port एक संभावित entry point है।
  20. Q20 — (a) इंसान और process
    Training, process और awareness के बिना tools अधूरे हैं।
