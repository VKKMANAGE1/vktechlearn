Chapter 4 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

हर सवाल का एक विकल्प चुनें और नीचे जवाब जमा करें दबाएँ — स्कोर और हर सवाल की व्याख्या तुरंत दिखेगी। 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. Vulnerability क्या है?

    सही उत्तर: System में कमज़ोरी — कमज़ोरी से system का सुरक्षा-ढाँचा कमज़ोर पड़ता है।

  2. CVE क्या होता है?

    सही उत्तर: कमज़ोरी का unique पहचान नंबर — हर publicly disclosed कमज़ोरी को CVE ID मिलती है।

  3. CVSS score किसके लिए होता है?

    सही उत्तर: Severity मापने के लिए — CVSS 0 से 10 तक गंभीरता बताता है।

  4. Buffer overflow कब होता है?

    सही उत्तर: Program तय जगह से ज़्यादा data ले ले — ज़्यादा data आस-पास की memory में लिख दिया जाता है।

  5. SQL Injection का मुख्य कारण क्या है?

    सही उत्तर: User input सीधे query में जोड़ना — बिना जाँच input query का मतलब बदल देता है।

  6. SQL Injection से बचाव का सही तरीका कौन सा है?

    सही उत्तर: Parameterized queries — Prepared statements से input code नहीं बन पाता।

  7. XSS में हमला किस पर होता है?

    सही उत्तर: दूसरे users के browser पर — दूसरों को दिखाया गया script उनके browser में चलता है।

  8. XSS का बचाव क्या है?

    सही उत्तर: Output encoding और CSP — Encoding से script text बन जाता है और CSP उसे रोकती है।

  9. CSRF में attacker क्या करवाता है?

    सही उत्तर: User के browser से बिना जाने request भेजवाता है — Logged-in user के session का फ़ायदा उठाकर action करवाया जाता है।

  10. CSRF से बचाव कौन सा है?

    सही उत्तर: CSRF token और SameSite cookies — Token से request की वैधता जाँची जाती है।

  11. Stored XSS कहाँ सेव होता है?

    सही उत्तर: Database में — Stored XSS database में रहता है और हर visitor को दिखता है।

  12. Reflected XSS कहाँ से आता है?

    सही उत्तर: URL या request के input से — Reflected XSS उसी request में तुरंत लौटता है।

  13. Vulnerability scan के false positive का मतलब क्या है?

    सही उत्तर: Tool ने कमज़ोरी बताई जो असल में नहीं है — इससे समय बर्बाद होता है, इसलिए verify करें।

  14. False negative क्यों ज़्यादा खतरनाक है?

    सही उत्तर: कमज़ोरी है पर पकड़ी नहीं गई — organization सोचता है सब ठीक है, जबकि जोखिम बना रहता है।

  15. किस tool से known exploits खोजे जाते हैं?

    सही उत्तर: searchsploit — searchsploit exploit database में खोजता है।

  16. Web app testing के लिए कौन सा tool आम है?

    सही उत्तर: Burp Suite — Burp/ZAP से requests जाँची और बदली जा सकती हैं।

  17. Exploitation में PoC कितना होना चाहिए?

    सही उत्तर: सिर्फ़ ज़रूरी proof — कम से कम असर वाला proof पर्याप्त है।

  18. Input validation किस काम आती है?

    सही उत्तर: गलत या खतरनाक input रोकना — लंबाई, type और format की जाँच से injection रुकती है।

  19. Default credentials क्यों खतरनाक हैं?

    सही उत्तर: सबको पता होते हैं — admin/admin जैसे default login तुरंत बदलने चाहिए।

  20. किसी वेबसाइट पर बिना अनुमति SQL injection test करना क्या है?

    सही उत्तर: अपराध — बिना अनुमति attack करना कानून का उल्लंघन है।
