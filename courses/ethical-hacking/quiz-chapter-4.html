Chapter 4 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

पहले सारे 20 के जवाब कागज़ पर लिखें, फिर नीचे उत्तर-कुंजी से जाँचें — 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. Vulnerability क्या है?

    1. System में कमज़ोरी
    2. एक tool
    3. एक protocol
    4. एक firewall

  2. CVE क्या होता है?

    1. कमज़ोरी का unique पहचान नंबर
    2. एक प्रकार का वायरस
    3. Firewall rule
    4. Port नंबर

  3. CVSS score किसके लिए होता है?

    1. Severity मापने के लिए
    2. File size के लिए
    3. Network speed के लिए
    4. Password length के लिए

  4. Buffer overflow कब होता है?

    1. Program तय जगह से ज़्यादा data ले ले
    2. Internet बंद हो
    3. Password लंबा हो
    4. फ़ाइल खुल न पाए

  5. SQL Injection का मुख्य कारण क्या है?

    1. User input सीधे query में जोड़ना
    2. Firewall बंद होना
    3. Wi-Fi कमज़ोर होना
    4. Password छोटा होना

  6. SQL Injection से बचाव का सही तरीका कौन सा है?

    1. Parameterized queries
    2. लंबा password
    3. नया antivirus
    4. Wi-Fi बंद करना

  7. XSS में हमला किस पर होता है?

    1. दूसरे users के browser पर
    2. सिर्फ़ server पर
    3. Router पर
    4. प्रिंटर पर

  8. XSS का बचाव क्या है?

    1. Output encoding और CSP
    2. सिर्फ़ HTTPS
    3. लंबा username
    4. डेटा डिलीट

  9. CSRF में attacker क्या करवाता है?

    1. User के browser से बिना जाने request भेजवाता है
    2. Server बंद करवाता है
    3. Wi-Fi बदलवाता है
    4. Printer चलवाता है

  10. CSRF से बचाव कौन सा है?

    1. CSRF token और SameSite cookies
    2. सिर्फ़ लंबा password
    3. एंटीवायरस
    4. Backup

  11. Stored XSS कहाँ सेव होता है?

    1. Database में
    2. केवल URL में
    3. Browser cache में
    4. Firewall में

  12. Reflected XSS कहाँ से आता है?

    1. URL या request के input से
    2. Database से
    3. Server के BIOS से
    4. Printer से

  13. Vulnerability scan के false positive का मतलब क्या है?

    1. Tool ने कमज़ोरी बताई जो असल में नहीं है
    2. कमज़ोरी छूट गई
    3. Tool crash हो गया
    4. Scan पूरा नहीं हुआ

  14. False negative क्यों ज़्यादा खतरनाक है?

    1. कमज़ोरी है पर पकड़ी नहीं गई
    2. कमज़ोरी नहीं है
    3. Tool धीमा है
    4. Report लंबी है

  15. किस tool से known exploits खोजे जाते हैं?

    1. searchsploit
    2. WinRAR
    3. Notepad
    4. VLC

  16. Web app testing के लिए कौन सा tool आम है?

    1. Burp Suite
    2. Excel
    3. Photoshop
    4. PowerPoint

  17. Exploitation में PoC कितना होना चाहिए?

    1. सिर्फ़ ज़रूरी proof
    2. पूरा data dump
    3. सारे users के passwords
    4. server बंद

  18. Input validation किस काम आती है?

    1. गलत या खतरनाक input रोकना
    2. Speed बढ़ाना
    3. रंग बदलना
    4. प्रिंट करना

  19. Default credentials क्यों खतरनाक हैं?

    1. सबको पता होते हैं
    2. बहुत लंबे होते हैं
    3. सिर्फ़ Linux में होते हैं
    4. महँगे होते हैं

  20. किसी वेबसाइट पर बिना अनुमति SQL injection test करना क्या है?

    1. अपराध
    2. Bug bounty
    3. Research
    4. सामान्य जाँच

उत्तर-कुंजी

  1. Q1 — (a) System में कमज़ोरी
    कमज़ोरी से system का सुरक्षा-ढाँचा कमज़ोर पड़ता है।
  2. Q2 — (a) कमज़ोरी का unique पहचान नंबर
    हर publicly disclosed कमज़ोरी को CVE ID मिलती है।
  3. Q3 — (a) Severity मापने के लिए
    CVSS 0 से 10 तक गंभीरता बताता है।
  4. Q4 — (a) Program तय जगह से ज़्यादा data ले ले
    ज़्यादा data आस-पास की memory में लिख दिया जाता है।
  5. Q5 — (a) User input सीधे query में जोड़ना
    बिना जाँच input query का मतलब बदल देता है।
  6. Q6 — (a) Parameterized queries
    Prepared statements से input code नहीं बन पाता।
  7. Q7 — (a) दूसरे users के browser पर
    दूसरों को दिखाया गया script उनके browser में चलता है।
  8. Q8 — (a) Output encoding और CSP
    Encoding से script text बन जाता है और CSP उसे रोकती है।
  9. Q9 — (a) User के browser से बिना जाने request भेजवाता है
    Logged-in user के session का फ़ायदा उठाकर action करवाया जाता है।
  10. Q10 — (a) CSRF token और SameSite cookies
    Token से request की वैधता जाँची जाती है।
  11. Q11 — (a) Database में
    Stored XSS database में रहता है और हर visitor को दिखता है।
  12. Q12 — (a) URL या request के input से
    Reflected XSS उसी request में तुरंत लौटता है।
  13. Q13 — (a) Tool ने कमज़ोरी बताई जो असल में नहीं है
    इससे समय बर्बाद होता है, इसलिए verify करें।
  14. Q14 — (a) कमज़ोरी है पर पकड़ी नहीं गई
    organization सोचता है सब ठीक है, जबकि जोखिम बना रहता है।
  15. Q15 — (a) searchsploit
    searchsploit exploit database में खोजता है।
  16. Q16 — (a) Burp Suite
    Burp/ZAP से requests जाँची और बदली जा सकती हैं।
  17. Q17 — (a) सिर्फ़ ज़रूरी proof
    कम से कम असर वाला proof पर्याप्त है।
  18. Q18 — (a) गलत या खतरनाक input रोकना
    लंबाई, type और format की जाँच से injection रुकती है।
  19. Q19 — (a) सबको पता होते हैं
    admin/admin जैसे default login तुरंत बदलने चाहिए।
  20. Q20 — (a) अपराध
    बिना अनुमति attack करना कानून का उल्लंघन है।
