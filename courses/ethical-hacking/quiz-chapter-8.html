Chapter 8 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

पहले सारे 20 के जवाब कागज़ पर लिखें, फिर नीचे उत्तर-कुंजी से जाँचें — 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. Social engineering में हमला किस पर होता है?

    1. इंसान पर
    2. सिर्फ़ server पर
    3. Firewall पर
    4. Printer पर

  2. Phishing क्या है?

    1. नकली ईमेल/साइट से जानकारी माँगना
    2. Wi-Fi तोड़ना
    3. Password hash बनाना
    4. Firewall बदलना

  3. Spear phishing किसके लिए होता है?

    1. किसी खास व्यक्ति के लिए तैयार
    2. सबके लिए एक जैसा
    3. सिर्फ़ कंपनियों के लिए
    4. सिर्फ़ बच्चों के लिए

  4. Vishing किस माध्यम से होता है?

    1. फोन कॉल
    2. ईमेल
    3. USB
    4. Wi-Fi

  5. Smishing किस माध्यम से होता है?

    1. SMS/WhatsApp
    2. प्रिंटर
    3. Scanner
    4. BIOS

  6. Pretexting में क्या किया जाता है?

    1. नकली कहानी बनाकर जानकारी माँगना
    2. Wi-Fi बंद करना
    3. Hash बनाना
    4. Port scan करना

  7. Baiting का उदाहरण क्या है?

    1. मुफ़्त ऑफ़र या छोड़ी हुई USB
    2. पोर्ट स्कैन
    3. फ़ायरवॉल नियम
    4. हैश तुलना

  8. Tailgating क्या है?

    1. किसी के पीछे restricted जगह में घुसना
    2. नेटवर्क कैबल चुराना
    3. ईमेल फ़ॉरवर्ड करना
    4. Password लिखना

  9. Authority का हथियार क्या है?

    1. अधिकारी बनकर डर पैदा करना
    2. मुफ़्त ऑफ़र
    3. जल्दबाज़ी
    4. जिज्ञासा

  10. Urgency का मतलब क्या है?

    1. जल्दी करने का दबाव
    2. लंबा इंतज़ार
    3. कोई दबाव नहीं
    4. सिर्फ़ रात में भेजना

  11. OTP किसे बताना चाहिए?

    1. किसी को नहीं
    2. बैंक को
    3. IT को
    4. जिसे भरोसा हो

  12. Phishing ईमेल की पहचान का सबसे अच्छा तरीका क्या है?

    1. प्रेषक का पूरा पता जाँचना
    2. सिर्फ़ नाम देखना
    3. सिर्फ़ logo देखना
    4. सिर्फ़ विषय देखना

  13. लिंक पर क्लिक करने से पहले क्या करें?

    1. Hover करके URL देखें
    2. तुरंत क्लिक करें
    3. दोस्त को भेजें
    4. Forward करें

  14. Phishing simulation के लिए क्या ज़रूरी है?

    1. लिखित अनुमति और policy
    2. सिर्फ़ tool
    3. सिर्फ़ ईमेल लिस्ट
    4. कुछ नहीं

  15. Simulation में असली password क्यों नहीं लेना चाहिए?

    1. यह अनैतिक और जोखिम भरा है
    2. सर्वर धीमा होता है
    3. ईमेल बड़ा होता है
    4. कोई कारण नहीं

  16. SPF, DKIM और DMARC किसके लिए हैं?

    1. ईमेल spoofing रोकने के लिए
    2. Wi-Fi तेज़ करने के लिए
    3. Password बदलने के लिए
    4. Port खोलने के लिए

  17. 2FA social engineering से कैसे बचाता है?

    1. Password चोरी होने पर भी login रोकता है
    2. ईमेल तेज़ करता है
    3. Wi-Fi बढ़ाता है
    4. Port बंद करता है

  18. Suspicious मेल मिलने पर क्या करें?

    1. Report करें और delete करें
    2. खोलकर देखें
    3. सबको forward करें
    4. उत्तर दें

  19. Awareness training का सही तरीका क्या है?

    1. सकारात्मक और नियमित
    2. डर और शर्मिंदगी
    3. साल में एक बार
    4. सिर्फ़ ईमेल

  20. Social engineering का सबसे अच्छा बचाव क्या है?

    1. शक होने पर रुककर पुष्टि करना
    2. हर लिंक खोलना
    3. OTP साझा करना
    4. Password सरल रखना

उत्तर-कुंजी

  1. Q1 — (a) इंसान पर
    यह भरोसा या डर पैदा करके जानकारी निकालता है।
  2. Q2 — (a) नकली ईमेल/साइट से जानकारी माँगना
    Phishing में भरोसेमंद बनकर संवेदनशील जानकारी माँगी जाती है।
  3. Q3 — (a) किसी खास व्यक्ति के लिए तैयार
    इसमें व्यक्ति की जानकारी इस्तेमाल करके संदेश व्यक्तिगत बनाया जाता है।
  4. Q4 — (a) फोन कॉल
    Vishing = voice phishing, फोन पर धोखा।
  5. Q5 — (a) SMS/WhatsApp
    Smishing में SMS या मैसेजिंग ऐप से नकली लिंक भेजे जाते हैं।
  6. Q6 — (a) नकली कहानी बनाकर जानकारी माँगना
    हमलावर नकली पहचान और कहानी से भरोसा बनाता है।
  7. Q7 — (a) मुफ़्त ऑफ़र या छोड़ी हुई USB
    लालच में user खुद खतरनाक चीज़ चला देता है।
  8. Q8 — (a) किसी के पीछे restricted जगह में घुसना
    शारीरिक पहुँच का फ़ायदा उठाया जाता है।
  9. Q9 — (a) अधिकारी बनकर डर पैदा करना
    "मैं IT से हूँ" जैसी बातें सोचने से रोकती हैं।
  10. Q10 — (a) जल्दी करने का दबाव
    "10 मिनट में खाता बंद" जैसी बातें सोचना रोक देती हैं।
  11. Q11 — (a) किसी को नहीं
    बैंक या IT कभी OTP नहीं माँगते।
  12. Q12 — (a) प्रेषक का पूरा पता जाँचना
    दिखने वाला नाम नकली हो सकता है, पता असली पहचान है।
  13. Q13 — (a) Hover करके URL देखें
    असली URL से नकली साइट पकड़ी जा सकती है।
  14. Q14 — (a) लिखित अनुमति और policy
    बिना अनुमति ऐसा अभियान अपराध हो सकता है।
  15. Q15 — (a) यह अनैतिक और जोखिम भरा है
    Awareness test में credential जमा करना ज़रूरी नहीं।
  16. Q16 — (a) ईमेल spoofing रोकने के लिए
    ये तीनों भेजने वाले की वैधता जाँचते हैं।
  17. Q17 — (a) Password चोरी होने पर भी login रोकता है
    दूसरी पुष्टि के बिना अटैकर login नहीं कर पाता।
  18. Q18 — (a) Report करें और delete करें
    Report से security team बाकी users को बचा सकती है।
  19. Q19 — (a) सकारात्मक और नियमित
    डर से लोग गलती छिपाते हैं; सीखने वाला माहौल बेहतर है।
  20. Q20 — (a) शक होने पर रुककर पुष्टि करना
    दूसरे channel से पुष्टि करने से धोखा टल जाता है।
