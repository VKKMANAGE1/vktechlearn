Chapter 6 · Malware Analysis और Reverse Engineering

Chapter 6 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

पहले सारे 20 के जवाब कागज़ पर लिखें, फिर नीचे उत्तर-कुंजी से जाँचें — 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. Malware क्या है?

    1. नुक़सान या चोरी के लिए बनाया software
    2. एक firewall
    3. एक protocol
    4. एक hardware

  2. Virus कैसे फैलता है?

    1. किसी फ़ाइल से जुड़कर, user के चलाने पर
    2. अपने आप नेटवर्क में
    3. सिर्फ़ Wi-Fi से
    4. सिर्फ़ Bluetooth से

  3. Worm की खास बात क्या है?

    1. बिना user के अपने आप फैलता है
    2. सिर्फ़ ईमेल में आता है
    3. कभी नहीं फैलता
    4. सिर्फ़ मोबाइल में

  4. Trojan कैसे आता है?

    1. उपयोगी program बनकर
    2. सिर्फ़ USB से
    3. सिर्फ़ BIOS से
    4. सिर्फ़ printer से

  5. Ransomware क्या करता है?

    1. फ़ाइलें encrypt करके फिरौती माँगता है
    2. सिर्फ़ धीमा करता है
    3. Wi-Fi बंद करता है
    4. प्रिंटर खराब करता है

  6. Keylogger क्या रिकॉर्ड करता है?

    1. Keyboard की keys
    2. सिर्फ़ फोटो
    3. सिर्फ़ आवाज़
    4. सिर्फ़ वीडियो

  7. Rootkit का मक़सद क्या है?

    1. System में छिपकर पकड़ से बचना
    2. Speed बढ़ाना
    3. Backup लेना
    4. Wi-Fi बढ़ाना

  8. Botnet क्या है?

    1. कई infected मशीनों का समूह
    2. एक antivirus
    3. एक firewall
    4. एक protocol

  9. Malware analysis कहाँ करना चाहिए?

    1. Isolated lab VM में
    2. अपने main laptop पर
    3. ऑफ़िस के server पर
    4. किसी दोस्त के फोन पर

  10. Static analysis में क्या किया जाता है?

    1. Code चलाए बिना पढ़ना
    2. Sample चलाना
    3. Network बंद करना
    4. Backup लेना

  11. Dynamic analysis में क्या देखा जाता है?

    1. चलते समय व्यवहार
    2. सिर्फ़ file size
    3. सिर्फ़ नाम
    4. सिर्फ़ hash

  12. Magic bytes से क्या पता चलता है?

    1. असली file type
    2. Password
    3. Owner का नाम
    4. File की उम्र

  13. Strings निकालने का फ़ायदा क्या है?

    1. URLs, paths और commands मिल सकते हैं
    2. File छोटी हो जाती है
    3. Virus मर जाता है
    4. सिर्फ़ रंग बदलता है

  14. Obfuscation का मक़सद क्या है?

    1. Code को समझना कठिन बनाना
    2. Code तेज़ करना
    3. File छोटी करना
    4. Backup लेना

  15. Python script में eval() दिखे तो क्या संकेत है?

    1. Dynamic code चलने का खतरा
    2. सिर्फ़ गणित
    3. सिर्फ़ print
    4. कोई संकेत नहीं

  16. Sample चलाने से पहले क्या ज़रूरी है?

    1. VM snapshot
    2. नया antivirus
    3. Wi-Fi बंद
    4. प्रिंटर

  17. Malware के network indicators किस काम आते हैं?

    1. Block rules और detection बनाने में
    2. Password बदलने में
    3. Wi-Fi तेज़ करने में
    4. प्रिंटर ठीक करने में

  18. Ransomware से बचाव का सबसे अच्छा तरीका क्या है?

    1. Offline backup
    2. सिर्फ़ antivirus
    3. नया laptop
    4. कम internet

  19. Pirated software क्यों खतरनाक है?

    1. उसमें malware हो सकता है
    2. वह धीमा होता है
    3. उसमें रंग नहीं होते
    4. वह महँगा होता है

  20. Malware sample को किसके साथ share करना चाहिए?

    1. सुरक्षित, authorized channel से
    2. सोशल media पर
    3. सबको ईमेल से
    4. किसी को नहीं, कभी नहीं

उत्तर-कुंजी

  1. Q1 — (a) नुक़सान या चोरी के लिए बनाया software
    Malware बिना अनुमति नुक़सान, चोरी या निगरानी के लिए बनाया जाता है।
  2. Q2 — (a) किसी फ़ाइल से जुड़कर, user के चलाने पर
    Virus को host फ़ाइल और user की क्रिया चाहिए।
  3. Q3 — (a) बिना user के अपने आप फैलता है
    Worm नेटवर्क में खुद फैलता है।
  4. Q4 — (a) उपयोगी program बनकर
    Trojan अंदर बुरा code छिपाए रहता है।
  5. Q5 — (a) फ़ाइलें encrypt करके फिरौती माँगता है
    Ransomware से बचाव का सबसे बड़ा हथियार offline backup है।
  6. Q6 — (a) Keyboard की keys
    Keylogger से passwords और संदेश चोरी हो सकते हैं।
  7. Q7 — (a) System में छिपकर पकड़ से बचना
    Rootkit detection को कठिन बनाता है।
  8. Q8 — (a) कई infected मशीनों का समूह
    Botnet से बड़े पैमाने पर हमले चलाए जाते हैं।
  9. Q9 — (a) Isolated lab VM में
    Sample कभी host machine पर नहीं चलाना चाहिए।
  10. Q10 — (a) Code चलाए बिना पढ़ना
    Static में strings, imports और file type देखे जाते हैं।
  11. Q11 — (a) चलते समय व्यवहार
    Dynamic में file changes, processes और network connections देखे जाते हैं।
  12. Q12 — (a) असली file type
    MZ, PK, %PDF जैसे bytes से format पहचाना जाता है।
  13. Q13 — (a) URLs, paths और commands मिल सकते हैं
    Plain text indicators से sample का व्यवहार समझ आता है।
  14. Q14 — (a) Code को समझना कठिन बनाना
    Base64/encoding और बेमतलब नाम analysis को रोकते हैं।
  15. Q15 — (a) Dynamic code चलने का खतरा
    eval/exec से छिपाया हुआ code चल सकता है।
  16. Q16 — (a) VM snapshot
    Snapshot से VM तुरंत पुरानी हालत में लौट सकती है।
  17. Q17 — (a) Block rules और detection बनाने में
    ज्ञात C2 domains/IPs से blocking और alerts बनते हैं।
  18. Q18 — (a) Offline backup
    Backup होने पर फ़ाइलें वापस लाई जा सकती हैं।
  19. Q19 — (a) उसमें malware हो सकता है
    Cracked installers में अक्सर malware छिपा होता है।
  20. Q20 — (a) सुरक्षित, authorized channel से
    Sample को सिर्फ़ ज़रूरत और सुरक्षित तरीके से share करें।
