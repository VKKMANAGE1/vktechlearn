Chapter 6 · Malware Analysis और Reverse Engineering

Chapter 6 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

हर सवाल का एक विकल्प चुनें और नीचे जवाब जमा करें दबाएँ — स्कोर और हर सवाल की व्याख्या तुरंत दिखेगी। 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. Malware क्या है?

    सही उत्तर: नुक़सान या चोरी के लिए बनाया software — Malware बिना अनुमति नुक़सान, चोरी या निगरानी के लिए बनाया जाता है।

  2. Virus कैसे फैलता है?

    सही उत्तर: किसी फ़ाइल से जुड़कर, user के चलाने पर — Virus को host फ़ाइल और user की क्रिया चाहिए।

  3. Worm की खास बात क्या है?

    सही उत्तर: बिना user के अपने आप फैलता है — Worm नेटवर्क में खुद फैलता है।

  4. Trojan कैसे आता है?

    सही उत्तर: उपयोगी program बनकर — Trojan अंदर बुरा code छिपाए रहता है।

  5. Ransomware क्या करता है?

    सही उत्तर: फ़ाइलें encrypt करके फिरौती माँगता है — Ransomware से बचाव का सबसे बड़ा हथियार offline backup है।

  6. Keylogger क्या रिकॉर्ड करता है?

    सही उत्तर: Keyboard की keys — Keylogger से passwords और संदेश चोरी हो सकते हैं।

  7. Rootkit का मक़सद क्या है?

    सही उत्तर: System में छिपकर पकड़ से बचना — Rootkit detection को कठिन बनाता है।

  8. Botnet क्या है?

    सही उत्तर: कई infected मशीनों का समूह — Botnet से बड़े पैमाने पर हमले चलाए जाते हैं।

  9. Malware analysis कहाँ करना चाहिए?

    सही उत्तर: Isolated lab VM में — Sample कभी host machine पर नहीं चलाना चाहिए।

  10. Static analysis में क्या किया जाता है?

    सही उत्तर: Code चलाए बिना पढ़ना — Static में strings, imports और file type देखे जाते हैं।

  11. Dynamic analysis में क्या देखा जाता है?

    सही उत्तर: चलते समय व्यवहार — Dynamic में file changes, processes और network connections देखे जाते हैं।

  12. Magic bytes से क्या पता चलता है?

    सही उत्तर: असली file type — MZ, PK, %PDF जैसे bytes से format पहचाना जाता है।

  13. Strings निकालने का फ़ायदा क्या है?

    सही उत्तर: URLs, paths और commands मिल सकते हैं — Plain text indicators से sample का व्यवहार समझ आता है।

  14. Obfuscation का मक़सद क्या है?

    सही उत्तर: Code को समझना कठिन बनाना — Base64/encoding और बेमतलब नाम analysis को रोकते हैं।

  15. Python script में eval() दिखे तो क्या संकेत है?

    सही उत्तर: Dynamic code चलने का खतरा — eval/exec से छिपाया हुआ code चल सकता है।

  16. Sample चलाने से पहले क्या ज़रूरी है?

    सही उत्तर: VM snapshot — Snapshot से VM तुरंत पुरानी हालत में लौट सकती है।

  17. Malware के network indicators किस काम आते हैं?

    सही उत्तर: Block rules और detection बनाने में — ज्ञात C2 domains/IPs से blocking और alerts बनते हैं।

  18. Ransomware से बचाव का सबसे अच्छा तरीका क्या है?

    सही उत्तर: Offline backup — Backup होने पर फ़ाइलें वापस लाई जा सकती हैं।

  19. Pirated software क्यों खतरनाक है?

    सही उत्तर: उसमें malware हो सकता है — Cracked installers में अक्सर malware छिपा होता है।

  20. Malware sample को किसके साथ share करना चाहिए?

    सही उत्तर: सुरक्षित, authorized channel से — Sample को सिर्फ़ ज़रूरत और सुरक्षित तरीके से share करें।
