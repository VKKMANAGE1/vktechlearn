Chapter 3 · Reconnaissance और Information Gathering

Chapter 3 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

हर सवाल का एक विकल्प चुनें और नीचे जवाब जमा करें दबाएँ — स्कोर और हर सवाल की व्याख्या तुरंत दिखेगी। 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. Passive reconnaissance में क्या नहीं होता?

    सही उत्तर: Target से सीधा संपर्क — Passive में target को request नहीं जाती; active में सीधा संपर्क होता है।

  2. WHOIS से क्या पता चलता है?

    सही उत्तर: Domain का registration data — WHOIS में registrar, creation date और name servers मिलते हैं।

  3. DNS का A record क्या बताता है?

    सही उत्तर: Domain का IP address — A record domain को IPv4 address से जोड़ता है।

  4. MX record किसके लिए होता है?

    सही उत्तर: Mail server — MX record बताता है कि domain के ईमेल किस server पर जाते हैं।

  5. Certificate transparency logs से क्या मिलता है?

    सही उत्तर: Subdomains की सूची — SSL certificates में subdomain नाम सार्वजनिक होते हैं।

  6. Job listings से recon में क्या पता चलता है?

    सही उत्तर: Tech stack का अंदाज़ा — माँगी गई technologies से organization का stack समझ आता है।

  7. Active recon का उदाहरण कौन सा है?

    सही उत्तर: Port scan — Port scan में target से सीधा संपर्क होता है।

  8. Recon का नतीजा कहाँ रखना चाहिए?

    सही उत्तर: व्यवस्थित notes और files में — notes.md, hosts.txt जैसी files से आगे का काम आसान होता है।

  9. OSINT का पूरा नाम क्या है?

    सही उत्तर: Open Source Intelligence — OSINT सार्वजनिक जानकारी से analysis है।

  10. site: operator का काम क्या है?

    सही उत्तर: एक साइट के अंदर खोजना — site:example.com से उसी domain के नतीजे मिलते हैं।

  11. Recon में scope का महत्व क्या है?

    सही उत्तर: सिर्फ़ अनुमति वाले targets पर रहना — Scope से बाहर का subdomain भी नहीं छूना चाहिए।

  12. Subdomain क्या होता है?

    सही उत्तर: मुख्य domain का उप-भाग, जैसे mail.example.com — mail, vpn, test जैसे subdomains attack surface बढ़ाते हैं।

  13. Python में WHOIS के लिए कौन सी library है?

    सही उत्तर: python-whois — python-whois से domain का registration data पढ़ा जाता है।

  14. dnspython library किसके लिए है?

    सही उत्तर: DNS records पढ़ने के लिए — dnspython से A, MX, TXT और NS records मिलते हैं।

  15. Certificate logs से subdomains पढ़ने का तरीका क्या है?

    सही उत्तर: crt.sh की JSON API से — crt.sh पर query करके name_value पढ़े जाते हैं।

  16. Active scanning से पहले क्या ज़रूरी है?

    सही उत्तर: लिखित अनुमति — बिना अनुमति scan करना कानून का उल्लंघन है।

  17. Recon का मुख्य फ़ायदा क्या है?

    सही उत्तर: हमले की सतह समझना — attack surface समझने से testing के लिए सही दिशा मिलती है।

  18. Tool के output को क्या करना चाहिए?

    सही उत्तर: verify करके notes में जोड़ना — हर जानकारी verify करके source के साथ रखें।

  19. किसी दूसरे के नेटवर्क पर active scan करने से क्या होता है?

    सही उत्तर: कानूनी जोखिम और logs में entry — बिना अनुमति scan अपराध है और target के logs में दर्ज होता है।

  20. Recon में public documents से क्या मिल सकता है?

    सही उत्तर: Metadata और versions — PDF/Word metadata से software versions और paths का अंदाज़ा मिलता है।
