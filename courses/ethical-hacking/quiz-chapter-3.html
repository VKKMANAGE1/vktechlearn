Chapter 3 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

पहले सारे 20 के जवाब कागज़ पर लिखें, फिर नीचे उत्तर-कुंजी से जाँचें — 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. Passive reconnaissance में क्या नहीं होता?

    1. Target से सीधा संपर्क
    2. Search engine का इस्तेमाल
    3. WHOIS lookup
    4. Public documents पढ़ना

  2. WHOIS से क्या पता चलता है?

    1. Domain का registration data
    2. सर्वर का पासवर्ड
    3. User का ईमेल inbox
    4. Wi-Fi का password

  3. DNS का A record क्या बताता है?

    1. Domain का IP address
    2. Mail server
    3. नाम server
    4. Text verification

  4. MX record किसके लिए होता है?

    1. Mail server
    2. Web server
    3. DNS server
    4. Proxy

  5. Certificate transparency logs से क्या मिलता है?

    1. Subdomains की सूची
    2. पासवर्ड
    3. Source code
    4. Firewall rules

  6. Job listings से recon में क्या पता चलता है?

    1. Tech stack का अंदाज़ा
    2. कर्मचारियों का पासवर्ड
    3. Server का IP
    4. Firewall का model

  7. Active recon का उदाहरण कौन सा है?

    1. Port scan
    2. WHOIS lookup
    3. Search engine search
    4. Archive.org

  8. Recon का नतीजा कहाँ रखना चाहिए?

    1. व्यवस्थित notes और files में
    2. ज़ुबानी याद
    3. किसी को भेजकर
    4. कागज़ पर कहीं

  9. OSINT का पूरा नाम क्या है?

    1. Open Source Intelligence
    2. Online System Info Tool
    3. Open Security Internet
    4. Operational Source Info

  10. site: operator का काम क्या है?

    1. एक साइट के अंदर खोजना
    2. फ़ाइल प्रकार तय करना
    3. साइट बनाना
    4. ईमेल भेजना

  11. Recon में scope का महत्व क्या है?

    1. सिर्फ़ अनुमति वाले targets पर रहना
    2. सब कुछ scan करना
    3. कोई सीमा नहीं
    4. सिर्फ़ passive करना

  12. Subdomain क्या होता है?

    1. मुख्य domain का उप-भाग, जैसे mail.example.com
    2. एक प्रकार का वायरस
    3. IP range
    4. Firewall

  13. Python में WHOIS के लिए कौन सी library है?

    1. python-whois
    2. requests-html
    3. numpy
    4. matplotlib

  14. dnspython library किसके लिए है?

    1. DNS records पढ़ने के लिए
    2. PDF बनाने के लिए
    3. Image edit के लिए
    4. Video के लिए

  15. Certificate logs से subdomains पढ़ने का तरीका क्या है?

    1. crt.sh की JSON API से
    2. किसी के फोन से
    3. Firewall से
    4. Wi-Fi से

  16. Active scanning से पहले क्या ज़रूरी है?

    1. लिखित अनुमति
    2. तेज़ internet
    3. नया लैपटॉप
    4. कोई नहीं

  17. Recon का मुख्य फ़ायदा क्या है?

    1. हमले की सतह समझना
    2. पासवर्ड मिलना
    3. Data बेचना
    4. Server बंद करना

  18. Tool के output को क्या करना चाहिए?

    1. verify करके notes में जोड़ना
    2. बिना देखे भेजना
    3. डिलीट करना
    4. छिपाना

  19. किसी दूसरे के नेटवर्क पर active scan करने से क्या होता है?

    1. कानूनी जोखिम और logs में entry
    2. कुछ नहीं
    3. सिर्फ़ speed बढ़ती है
    4. Wi-Fi तेज़ होता है

  20. Recon में public documents से क्या मिल सकता है?

    1. Metadata और versions
    2. पासवर्ड
    3. Bank details
    4. कुछ नहीं

उत्तर-कुंजी

  1. Q1 — (a) Target से सीधा संपर्क
    Passive में target को request नहीं जाती; active में सीधा संपर्क होता है।
  2. Q2 — (a) Domain का registration data
    WHOIS में registrar, creation date और name servers मिलते हैं।
  3. Q3 — (a) Domain का IP address
    A record domain को IPv4 address से जोड़ता है।
  4. Q4 — (a) Mail server
    MX record बताता है कि domain के ईमेल किस server पर जाते हैं।
  5. Q5 — (a) Subdomains की सूची
    SSL certificates में subdomain नाम सार्वजनिक होते हैं।
  6. Q6 — (a) Tech stack का अंदाज़ा
    माँगी गई technologies से organization का stack समझ आता है।
  7. Q7 — (a) Port scan
    Port scan में target से सीधा संपर्क होता है।
  8. Q8 — (a) व्यवस्थित notes और files में
    notes.md, hosts.txt जैसी files से आगे का काम आसान होता है।
  9. Q9 — (a) Open Source Intelligence
    OSINT सार्वजनिक जानकारी से analysis है।
  10. Q10 — (a) एक साइट के अंदर खोजना
    site:example.com से उसी domain के नतीजे मिलते हैं।
  11. Q11 — (a) सिर्फ़ अनुमति वाले targets पर रहना
    Scope से बाहर का subdomain भी नहीं छूना चाहिए।
  12. Q12 — (a) मुख्य domain का उप-भाग, जैसे mail.example.com
    mail, vpn, test जैसे subdomains attack surface बढ़ाते हैं।
  13. Q13 — (a) python-whois
    python-whois से domain का registration data पढ़ा जाता है।
  14. Q14 — (a) DNS records पढ़ने के लिए
    dnspython से A, MX, TXT और NS records मिलते हैं।
  15. Q15 — (a) crt.sh की JSON API से
    crt.sh पर query करके name_value पढ़े जाते हैं।
  16. Q16 — (a) लिखित अनुमति
    बिना अनुमति scan करना कानून का उल्लंघन है।
  17. Q17 — (a) हमले की सतह समझना
    attack surface समझने से testing के लिए सही दिशा मिलती है।
  18. Q18 — (a) verify करके notes में जोड़ना
    हर जानकारी verify करके source के साथ रखें।
  19. Q19 — (a) कानूनी जोखिम और logs में entry
    बिना अनुमति scan अपराध है और target के logs में दर्ज होता है।
  20. Q20 — (a) Metadata और versions
    PDF/Word metadata से software versions और paths का अंदाज़ा मिलता है।
