Python Scripts लिखना और काम Automate करना

लेसन 4 / 20·~6 मिनट·by Vïnâý Kúshwâhå

एक बार Python की बुनियाद आ जाए, तो असली फ़ायदा scripts से मिलता है — बार-बार होने वाला काम अपने आप। Recon की सूची बनाना हो, files में से IP निकालने हों या किसी target के headers देखने हों, छोटा script मिनटों का काम सेकंडों में कर देता है। इस लेसन में script लिखने, चलाने और उसे reusable बनाने का तरीका देखेंगे।

Script बनाना और चलाना

  1. Kali में terminal खोलें और nano scan.py से फ़ाइल बनाएँ।
  2. कोड लिखें और Ctrl+O, Enter, Ctrl+X से सेव करें।
  3. python3 scan.py से चलाएँ।
  4. चलाने की अनुमति चाहिए तो chmod +x scan.py दें और पहली पंक्ति में #!/usr/bin/env python3 लिखें।

Command-line arguments

हर बार code में target बदलना ठीक नहीं। argparse से script को options दें:

import argparse

parser = argparse.ArgumentParser(description="Host checker")
parser.add_argument("host", help="target IP")
parser.add_argument("-p", "--port", type=int, default=80)
args = parser.parse_args()

print(args.host, args.port)

अब python3 check.py 192.168.56.101 -p 22 चलेगा। Arguments से script दोबारा लिखे बिना अलग-अलग target पर चल सकती है।

File से सूची पढ़ना

with open("hosts.txt") as f:
    hosts = [line.strip() for line in f if line.strip()]

for host in hosts:
    print("checking", host)

Recon में अक्सर सैकड़ों subdomain या IP होते हैं। उन्हें फ़ाइल में रखकर loop चलाना सबसे साफ़ तरीका है। हर request के बीच छोटा pause रखें, ताकि target पर अनचाहा load न पड़े।

HTTP Headers देखना

import requests

r = requests.get("http://192.168.56.101", timeout=5)
print(r.status_code)
print(r.headers.get("Server"))

Headers से पता चलता है कि कौन सा server चल रहा है और कुछ security headers मौजूद हैं या नहीं। यह जानकारी authorized testing में configuration समझने के लिए काम आती है।

Result सेव करना

Terminal पर छपा result खो जाता है। उसे JSON में सेव करें, ताकि बाद में report बने:

import json

report = {"host": "192.168.56.101", "open_ports": [22, 80]}
with open("result.json", "w") as f:
    json.dump(report, f, indent=2)

Automation के नियम

  • Rate limit: बहुत तेज़ requests से target धीमा या बंद हो सकता है — अनुमति वाली सीमा में रहें।
  • Logging: script क्या-क्या कर रही है, फ़ाइल में लिखें — बाद में सबूत काम आता है।
  • Dry run: पहले बिना असर वाले mode में चलाएँ, फिर असली।
  • Cleanup: जो फ़ाइलें या changes बनाएँ, अंत में हटाएँ।
याद रखें
  • argparse से script reusable बनती है
  • सूची फ़ाइल से पढ़कर loop चलाना आम तरीका है
  • Result हमेशा JSON/CSV में सेव करें
  • Automation में धीमी गति और logging ज़रूरी
Practical — 15 मिनट

एक script बनाएँ जो hosts.txt से IP पढ़े और हर एक के लिए status code print करे। Result को result.json में सेव करें। सिर्फ़ अपनी lab VM के IP इस्तेमाल करें।
