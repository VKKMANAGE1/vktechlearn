Chapter 1 · Ethical Hacking का परिचय

अपना Hacking Lab सेट करना — Kali Linux और Virtual Machine

लेसन 2 / 20·~7 मिनट·by Vïnâý Kúshwâhå

Hacking सीखने का सबसे सुरक्षित तरीका है अपना अलग lab — एक virtual machine जिसमें आप जो चाहें try करें, और ग़लती होने पर सिर्फ़ वही VM खराब हो, आपका असली कंप्यूटर नहीं। इस लेसन में lab के हिस्से, Kali Linux और एक vulnerable target machine को सेट करने का तरीका देखेंगे।

Lab में क्या-क्या चाहिए

हिस्साकाम
Host machineआपका असली लैपटॉप — यहाँ कुछ भी test नहीं करना
VirtualBox / VMwareVM चलाने का सॉफ्टवेयर
Kali Linux VMsecurity tools वाला Linux, attacker की जगह
Target VMजान-बूझकर कमज़ोर बनाई गई मशीन, practice के लिए
Host-only नेटवर्कदोनों VM आपस में जुड़ें, बाहर न जाएँ

1. VirtualBox install करें

VirtualBox मुफ़्त है और Windows, Linux व macOS पर चलता है। install के बाद एक नई VM बनाएँ: type Linux, version Debian (64-bit), memory कम से कम 4 GB और disk 25 GB. अगर लैपटॉप में 8 GB RAM है तो Kali को 3 GB दें और target को 1–2 GB — दोनों एक साथ चलेंगे।

2. Kali Linux सेट करें

  1. kali.org से VirtualBox के लिए बनी image डाउनलोड करें।
  2. VirtualBox में Import Appliance से फ़ाइल खोलें।
  3. चलने के बाद default username/password बदल दें।
  4. Terminal खोलकर python3 --version और pip3 --version से Python जाँचें।
  5. sudo apt update चलाकर packages अपडेट करें।

Kali में बहुत से tools पहले से होते हैं, पर शुरुआत में सिर्फ़ Python, browser और network tools ही काफ़ी हैं। हर tool install करने की ज़रूरत नहीं — पहले concept साफ़ करें।

3. Practice के लिए Target VM

अपने ही lab में attack करने के लिए कुछ मुफ़्त vulnerable machines उपलब्ध हैं, जिन्हें जान-बूझकर कमज़ोर बनाया गया है — जैसे Metasploitable और OWASP से जुड़ी practice machines। इन्हें सिर्फ़ host-only नेटवर्क में चलाएँ, इंटरनेट से जोड़ें ही नहीं।

4. नेटवर्क अलग रखें

VirtualBox की सेटिंग में Network → Adapter को Host-only Adapter चुनें। इससे VM आपस में बात कर सकती हैं, पर आपके घर का बाकी नेटवर्क और इंटरनेट सुरक्षित रहता है। NAT मोड सिर्फ़ तब इस्तेमाल करें जब VM में updates डाउनलोड करने हों।

Lab के सुनहरे नियम
  • Practice सिर्फ़ अपनी VM पर — कभी असली नेटवर्क या दूसरों के डिवाइस पर नहीं
  • Host-only नेटवर्क रखें, target को इंटरनेट से न जोड़ें
  • हर practice के बाद VM snapshot लें, ताकि गड़बड़ होने पर वापस जा सकें

5. Snapshot और Reset

कुछ भी बदलने से पहले VM का snapshot बना लें। अगर कोई test VM को खराब कर दे, तो कुछ सेकंड में पुरानी हालत में लौट सकते हैं। यही आदत असली pentest में भी काम आती है — बदलाव से पहले backup।

6. पहला safe check

Kali में terminal खोलकर ip a चलाएँ — अपनी VM का IP दिखेगा, जैसे 192.168.56.101। फिर target VM का IP देखें। दोनों अलग हों और एक-दूसरे को ping कर सकें, तो lab तैयार है।

याद रखें: lab का मक़सद सिर्फ़ सीखना है। जो तकनीक यहाँ सीखेंगे, वह असली दुनिया में सिर्फ़ लिखित अनुमति वाले systems पर ही लागू करें।

Practical — 20 मिनट

VirtualBox में Kali VM import करें, host-only नेटवर्क सेट करें और ip a चलाकर अपना IP नोट करें। एक snapshot बनाएँ और उसका नाम "clean-install" रखें।
