Chapter 5 · Password Cracking और Wireless Hacking

Chapter 5 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

पहले सारे 20 के जवाब कागज़ पर लिखें, फिर नीचे उत्तर-कुंजी से जाँचें — 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. अच्छी वेबसाइट password कैसे रखती है?

    1. Hash के रूप में
    2. Plain text में
    3. Screenshot में
    4. Email में

  2. Hash function की खास बात क्या है?

    1. एक तरफ़ा — वापस नहीं खुलता
    2. दोनों तरफ़ खुलता है
    3. सिर्फ़ images पर चलता है
    4. इससे password बढ़ता है

  3. Password के लिए कौन सा hash सबसे उपयुक्त है?

    1. bcrypt/Argon2
    2. MD5
    3. SHA-1
    4. ROT13

  4. Salt क्या करता है?

    1. हर hash को unique बनाता है
    2. Password छोटा करता है
    3. Server तेज़ करता है
    4. Wi-Fi बढ़ाता है

  5. Brute force attack क्या है?

    1. हर संभव combination आज़माना
    2. सिर्फ़ एक password आज़माना
    3. Wi-Fi बंद करना
    4. ईमेल भेजना

  6. Dictionary attack किस पर आधारित है?

    1. आम passwords की सूची
    2. Hardware की गति
    3. Wi-Fi signal
    4. Firewall rules

  7. Credential stuffing क्या है?

    1. किसी और breach के leaked जोड़े दूसरी साइट पर आज़माना
    2. नया password बनाना
    3. 2FA चालू करना
    4. Password manager

  8. मज़बूत password की सबसे बड़ी खासियत क्या है?

    1. लंबाई
    2. सिर्फ़ symbol
    3. नाम + साल
    4. छोटा और याद रखने लायक

  9. 2FA क्या है?

    1. दो तरीक़ों से पहचान की जाँच
    2. दो passwords
    3. दो ईमेल
    4. दो antivirus

  10. Password manager का फ़ायदा क्या है?

    1. हर साइट के लिए अलग मज़बूत password
    2. password सबको बताना
    3. कम सुरक्षा
    4. Wi-Fi तेज़ करना

  11. WEP की स्थिति क्या है?

    1. पुराना और टूट चुका
    2. सबसे सुरक्षित
    3. नया standard
    4. सिर्फ़ 5G के लिए

  12. आज Wi-Fi के लिए सबसे अच्छा विकल्प कौन सा है?

    1. WPA3 (या WPA2)
    2. WEP
    3. Open
    4. WPA

  13. WPA2 में handshake क्या है?

    1. Router और device के बीच key verify करने की प्रक्रिया
    2. एक वायरस
    3. एक cable
    4. एक firewall

  14. Handshake पकड़ने पर हमलावर क्या कर सकता है?

    1. Offline password guessing
    2. Server बंद
    3. Wi-Fi तेज़
    4. कोई नहीं

  15. WPS के बारे में सही बात क्या है?

    1. इसे बंद रखना चाहिए
    2. इसे हमेशा चालू रखें
    3. यह password बदलता है
    4. यह firewall है

  16. Guest network का सही इस्तेमाल क्या है?

    1. मेहमानों को internal network से अलग रखना
    2. Admin access देना
    3. सबको एक ही password
    4. Firewall बंद करना

  17. Router की सुरक्षा के लिए क्या करें?

    1. Admin password बदलें और firmware अपडेट रखें
    2. Default password रखें
    3. Remote management चालू रखें
    4. WPS चालू रखें

  18. किसी दूसरे के Wi-Fi पर test करने के लिए क्या चाहिए?

    1. लिखित अनुमति
    2. सिर्फ़ लैपटॉप
    3. नया router
    4. कुछ नहीं

  19. Wi-Fi password कितना लंबा होना चाहिए?

    1. 16+ random अक्षर
    2. 8 अक्षर
    3. 4 अंक
    4. मोबाइल नंबर

  20. Open Wi-Fi नेटवर्क पर क्या जोखिम है?

    1. Data बिना encryption के जाता है
    2. कोई जोखिम नहीं
    3. सिर्फ़ speed कम होती है
    4. बैटरी खत्म होती है

उत्तर-कुंजी

  1. Q1 — (a) Hash के रूप में
    Hash one-way होता है, इसलिए password सीधे पढ़ा नहीं जा सकता।
  2. Q2 — (a) एक तरफ़ा — वापस नहीं खुलता
    Hash से original value वापस नहीं निकाली जा सकती।
  3. Q3 — (a) bcrypt/Argon2
    bcrypt/Argon2 जान-बूझकर धीमे होते हैं, जिससे guessing महँगी पड़ती है।
  4. Q4 — (a) हर hash को unique बनाता है
    Salt से rainbow tables बेकार हो जाती हैं।
  5. Q5 — (a) हर संभव combination आज़माना
    छोटे password पर brute force जल्दी सफल हो सकता है।
  6. Q6 — (a) आम passwords की सूची
    आम शब्द और leaked passwords की सूची आज़माई जाती है।
  7. Q7 — (a) किसी और breach के leaked जोड़े दूसरी साइट पर आज़माना
    इसलिए हर साइट पर अलग password ज़रूरी है।
  8. Q8 — (a) लंबाई
    लंबा random passphrase सबसे ज़्यादा सुरक्षा देता है।
  9. Q9 — (a) दो तरीक़ों से पहचान की जाँच
    Password के अलावा OTP/app से दूसरी पुष्टि होती है।
  10. Q10 — (a) हर साइट के लिए अलग मज़बूत password
    एक master password से बाकी सब सुरक्षित रहते हैं।
  11. Q11 — (a) पुराना और टूट चुका
    WEP कुछ ही मिनटों में तोड़ा जा सकता है।
  12. Q12 — (a) WPA3 (या WPA2)
    WPA3 सबसे नया और सुरक्षित है; router support न हो तो WPA2।
  13. Q13 — (a) Router और device के बीच key verify करने की प्रक्रिया
    4-way handshake में password से बनी key जाँची जाती है।
  14. Q14 — (a) Offline password guessing
    इसीलिए लंबा और random Wi-Fi password ज़रूरी है।
  15. Q15 — (a) इसे बंद रखना चाहिए
    WPS PIN से जुड़ना आसान हो जाता है, इसलिए बंद रखें।
  16. Q16 — (a) मेहमानों को internal network से अलग रखना
    Guest network अलग रहता है, जिससे internal systems सुरक्षित रहते हैं।
  17. Q17 — (a) Admin password बदलें और firmware अपडेट रखें
    Default admin login सबसे आम कमज़ोरी है।
  18. Q18 — (a) लिखित अनुमति
    बिना अनुमति wireless testing अपराध है।
  19. Q19 — (a) 16+ random अक्षर
    लंबा random password offline guessing को बहुत कठिन बनाता है।
  20. Q20 — (a) Data बिना encryption के जाता है
    बिना encryption के data दूसरे पढ़ सकते हैं; सार्वजनिक Wi-Fi पर संवेदनशील काम न करें।
