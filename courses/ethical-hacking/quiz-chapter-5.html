Chapter 5 · Password Cracking और Wireless Hacking

Chapter 5 टेस्ट — 20 सवाल

20 प्रश्न·हर सवाल 1 अंक·उत्तर अंत में

हर सवाल का एक विकल्प चुनें और नीचे जवाब जमा करें दबाएँ — स्कोर और हर सवाल की व्याख्या तुरंत दिखेगी। 16 या ज़्यादा सही मतलब चैप्टर ठीक से समझ आ गया है।

  1. अच्छी वेबसाइट password कैसे रखती है?

    सही उत्तर: Hash के रूप में — Hash one-way होता है, इसलिए password सीधे पढ़ा नहीं जा सकता।

  2. Hash function की खास बात क्या है?

    सही उत्तर: एक तरफ़ा — वापस नहीं खुलता — Hash से original value वापस नहीं निकाली जा सकती।

  3. Password के लिए कौन सा hash सबसे उपयुक्त है?

    सही उत्तर: bcrypt/Argon2 — bcrypt/Argon2 जान-बूझकर धीमे होते हैं, जिससे guessing महँगी पड़ती है।

  4. Salt क्या करता है?

    सही उत्तर: हर hash को unique बनाता है — Salt से rainbow tables बेकार हो जाती हैं।

  5. Brute force attack क्या है?

    सही उत्तर: हर संभव combination आज़माना — छोटे password पर brute force जल्दी सफल हो सकता है।

  6. Dictionary attack किस पर आधारित है?

    सही उत्तर: आम passwords की सूची — आम शब्द और leaked passwords की सूची आज़माई जाती है।

  7. Credential stuffing क्या है?

    सही उत्तर: किसी और breach के leaked जोड़े दूसरी साइट पर आज़माना — इसलिए हर साइट पर अलग password ज़रूरी है।

  8. मज़बूत password की सबसे बड़ी खासियत क्या है?

    सही उत्तर: लंबाई — लंबा random passphrase सबसे ज़्यादा सुरक्षा देता है।

  9. 2FA क्या है?

    सही उत्तर: दो तरीक़ों से पहचान की जाँच — Password के अलावा OTP/app से दूसरी पुष्टि होती है।

  10. Password manager का फ़ायदा क्या है?

    सही उत्तर: हर साइट के लिए अलग मज़बूत password — एक master password से बाकी सब सुरक्षित रहते हैं।

  11. WEP की स्थिति क्या है?

    सही उत्तर: पुराना और टूट चुका — WEP कुछ ही मिनटों में तोड़ा जा सकता है।

  12. आज Wi-Fi के लिए सबसे अच्छा विकल्प कौन सा है?

    सही उत्तर: WPA3 (या WPA2) — WPA3 सबसे नया और सुरक्षित है; router support न हो तो WPA2।

  13. WPA2 में handshake क्या है?

    सही उत्तर: Router और device के बीच key verify करने की प्रक्रिया — 4-way handshake में password से बनी key जाँची जाती है।

  14. Handshake पकड़ने पर हमलावर क्या कर सकता है?

    सही उत्तर: Offline password guessing — इसीलिए लंबा और random Wi-Fi password ज़रूरी है।

  15. WPS के बारे में सही बात क्या है?

    सही उत्तर: इसे बंद रखना चाहिए — WPS PIN से जुड़ना आसान हो जाता है, इसलिए बंद रखें।

  16. Guest network का सही इस्तेमाल क्या है?

    सही उत्तर: मेहमानों को internal network से अलग रखना — Guest network अलग रहता है, जिससे internal systems सुरक्षित रहते हैं।

  17. Router की सुरक्षा के लिए क्या करें?

    सही उत्तर: Admin password बदलें और firmware अपडेट रखें — Default admin login सबसे आम कमज़ोरी है।

  18. किसी दूसरे के Wi-Fi पर test करने के लिए क्या चाहिए?

    सही उत्तर: लिखित अनुमति — बिना अनुमति wireless testing अपराध है।

  19. Wi-Fi password कितना लंबा होना चाहिए?

    सही उत्तर: 16+ random अक्षर — लंबा random password offline guessing को बहुत कठिन बनाता है।

  20. Open Wi-Fi नेटवर्क पर क्या जोखिम है?

    सही उत्तर: Data बिना encryption के जाता है — बिना encryption के data दूसरे पढ़ सकते हैं; सार्वजनिक Wi-Fi पर संवेदनशील काम न करें।
