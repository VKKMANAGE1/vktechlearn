Phishing Simulation और Countermeasures

लेसन 16 / 20·~6 मिनट·by Vïnâý Kúshwâhå

Phishing simulation एक authorized awareness अभियान है, जिसमें संगठन अपने कर्मचारियों को नकली संदेश भेजकर देखता है कि वे कितनी सतर्कता से पहचान करते हैं। यह कोर्स के ethical दायरे में सिर्फ़ तब है जब लिखित अनुमति, साफ़ नीति और training plan हो।

अभियान की योजना

  1. अनुमति: management और HR की लिखित सहमति।
  2. उद्देश्य: training और सुधार — किसी को फँसाना नहीं।
  3. Scope: कौन से विभाग, कितने लोग, कब तक।
  4. Template: वास्तविक जैसा पर स्पष्ट रूप से सुरक्षित नकली संदेश।
  5. Tracking: कितने लोगों ने खोला, क्लिक किया, report किया।
  6. Debrief: परिणाम साझा करना, दोष नहीं — सीखना।

नकली संदेश कैसा हो

  • असली domain की जगह training domain इस्तेमाल करें।
  • नकली login page पर password कभी न लें; सिर्फ़ "आपने क्लिक किया" दर्ज करें।
  • संदेश के अंत में साफ़ लिखें कि यह awareness test था।
  • संवेदनशील या डराने वाला content न रखें।

Detection — ईमेल के संकेत

संकेतक्या देखें
प्रेषकdomain की स्पेलिंग, reply-to अलग होना
लिंकhover पर असली URL, छोटा किया गया link
भाषाजल्दबाज़ी, धमकी, बहुत बड़ा ऑफ़र
Attachmentअनजान .exe, .zip, macro वाली फ़ाइल
Greetingसामान्य "Dear customer" — नाम नहीं

Python से detection tool

पहले से मिले suspicious patterns से एक सरल checker बनाया जा सकता है:

import re

def risk_score(subject, body):
    score = 0
    if re.search(r"urgent|immediately|verify now", body, re.I):
        score += 2
    if re.search(r"https?://\d+\.\d+\.\d+\.\d+", body):
        score += 3
    if re.search(r"password|otp|account suspended", body, re.I):
        score += 1
    return score

print(risk_score("Account alert", "Verify now at http://192.168.1.5/login"))

यह सिर्फ़ शुरुआती संकेत देता है; असली filters में header analysis, domain reputation और attachment scanning जुड़ता है।

Countermeasures

  • SPF, DKIM, DMARC से नकली sender रोकें।
  • ईमेल gateway पर link और attachment scanning।
  • 2FA — password चोरी होने पर भी सुरक्षा।
  • आसान "Report phishing" बटन।
  • नियमित, छोटी और सकारात्मक training।
याद रखें
  • Simulation सिर्फ़ लिखित अनुमति से
  • नकली page पर असली password कभी न लें
  • Domain, link, भाषा और attachment — चार जाँच
  • मक़सद training है, किसी को नीचा दिखाना नहीं
Practical — 10 मिनट

अपने संगठन या घर के लिए 5 बिंदुओं की phishing awareness चेकलिस्ट लिखें। हर बिंदु के आगे बताएँ कि कर्मचारी को क्या करना चाहिए — delete, report या verify।
