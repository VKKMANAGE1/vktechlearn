अपने खाते में login करें

Google से जारी रखें — एक क्लिक, कोई नया password नहीं. आपकी keys और channel पहले से सेव मिलेंगी.

Google बटन न चले? यहाँ client ID / origin जाँचें (public id — कोई secret नहीं)

Google Cloud → APIs & Services → Credentials → OAuth client (Web application) की Client ID यहाँ सेव करें. उसी client में “Authorized JavaScript origins” में यह origin ज़रूर जोड़ें: https://vktechlearn.site

  • keys, channel और रिपोर्ट — सब आपके खाते में सेव, दोबारा कुछ लिखना नहीं
  • कोई नया password नहीं — पहचान Google ही बनाता है
  • कभी भी Google permissions से हटा सकते हैं

पहली बार आ रहे हैं? वही Google बटन आपका खाता बना देगा — keys बाद में Studio में एक बार सेव होंगी.
