अब तक हमने कंप्यूटर को बाहर से समझा। अब स्क्रीन के सामने बैठकर काम करने की बारी है। Windows दुनिया का सबसे ज़्यादा इस्तेमाल होने वाला डेस्कटॉप ऑपरेटिंग सिस्टम है, और इसका पूरा आधार चार चीज़ों पर टिका है — Desktop, Start menu, Taskbar और File Explorer। इन्हें ठीक से समझ लें, तो बाकी सब अपने आप आसान लगने लगता है।

बूटिंग से डेस्कटॉप तक

बिजली बटन दबाने पर कंप्यूटर पहले POST करता है (जाँचता है कि RAM, keyboard, disk ठीक हैं या नहीं), फिर BIOS/UEFI बूट डिवाइस ढूँढता है, फिर Windows लोड होता है। लॉगिन के बाद जो स्क्रीन दिखती है, वही Desktop है — उस पर background (wallpaper), icons और नीचे Taskbar होता है।

Desktop के हिस्से

  • Icons: This PC, Recycle Bin, फ़ोल्डर और शॉर्टकट। डबल-क्लिक से खुलते हैं।
  • Taskbar: नीचे की पट्टी — Start बटन, search, खुले ऐप्स और घड़ी/तारीख।
  • System Tray: दाईं ओर Wi-Fi, आवाज़, बैटरी और background ऐप्स के आइकन।
  • Notification Center: Win + N या घड़ी पर क्लिक — notifications और quick settings।
  • Recycle Bin: डिलीट की गई फ़ाइलें यहाँ रहती हैं; खाली करने से पहले जाँच लें।

Start Menu

Windows बटन (या keyboard पर Windows key) दबाने पर Start menu खुलता है। यहीं से हर ऐप चलाया जा सकता है। इसमें pinned apps, recent files, search box और power options (Shut down, Restart, Sleep) होते हैं। नया ऐप इंस्टॉल करने के बाद उसे Start menu में pin कर सकते हैं।

File Explorer — फ़ाइलों का घर

File Explorer (पुराना नाम Windows Explorer) खोलने के लिए Win + E दबाएँ। यहाँ ड्राइव, फ़ोल्डर और फ़ाइलें दिखती हैं। कुछ ज़रूरी बातें:

  • This PC: C: ड्राइव (जहाँ Windows और प्रोग्राम रहते हैं), D: ड्राइव, पेन ड्राइव और नेटवर्क ड्राइव।
  • Path/Address bar: ऊपर लिखा रास्ता, जैसे C:\Users\Name\Documents।
  • View: Large icons, Details, List — फ़ाइलें कैसे दिखें।
  • Sort और Group: नाम, तारीख, size के हिसाब से फ़ाइलें जमाना।
  • Search box: किसी फ़ोल्डर में फ़ाइल ढूँढने के लिए।

फ़ाइल के नाम और extension

हर फ़ाइल के नाम के आगे एक extension होता है जो बताता है कि वह किस तरह की फ़ाइल है — .docx (Word), .xlsx (Excel), .jpg (फोटो), .mp4 (वीडियो), .exe (प्रोग्राम)। Extension बदलने से फ़ाइल का असली फ़ॉर्मेट नहीं बदलता, इसलिए नाम बदलते समय सिर्फ़ नाम बदलें, extension नहीं।

Settings और Control Panel

Win + I से Settings खुलती है। यहाँ से Wi-Fi, Bluetooth, Display, Sound, Apps, Accounts, Time & Language और Windows Update जैसी चीज़ें बदली जाती हैं। पुराने कंप्यूटर में कुछ सेटिंग Control Panel में मिलती हैं — जैसे Programs uninstall करना या Devices देखना।

रोज़ काम के 5 शॉर्टकट
  • Win + E — File Explorer
  • Win + I — Settings
  • Alt + Tab — खुले ऐप्स के बीच बदलना
  • Win + D — सारे विंडो छोटे करके डेस्कटॉप दिखाना
  • Ctrl + S — फ़ाइल सेव करना

आगे क्या

Windows की बुनियादी समझ हो गई। अगले चैप्टर में input, output और storage डिवाइस की बारी है — जो कंप्यूटर से जुड़कर डेटा का आना-जाना और सेव होना संभालते हैं।

Practical — 10 मिनट

Desktop पर एक फ़ोल्डर बनाएँ, उसका नाम Practice रखें। उसमें एक नोटपैड फ़ाइल बनाकर कुछ लिखें और सेव करें। फिर उसे copy करके दूसरे फ़ोल्डर में paste करें, नाम बदलें और देखें कि extension नहीं बदला।
