Wi-Fi हर घर और दफ़्तर की रीढ़ है, और इसीलिए हमलावरों की पहली पसंद। इस लेसन में wireless सुरक्षा के प्रकार, handshake का मतलब और अपने ही नेटवर्क की जाँच करने का तरीका समझेंगे — दूसरों के Wi-Fi पर कोई test बिना अनुमति नहीं।

Wi-Fi सुरक्षा के प्रकार

प्रकारस्थितिटिप्पणी

WPA2 में handshake क्या है

जब कोई device Wi-Fi से जुड़ता है, तो router और device के बीच एक 4-way handshake होता है, जिसमें password से बनी key verify होती है। अगर कोई हमलावर handshake पकड़ ले, तो वह offline तरीके से password guesses आज़मा सकता है। इसीलिए मज़बूत, लंबा Wi-Fi password ज़रूरी है — 8 अक्षरों का आसान password ऑफ़लाइन जल्दी टूट सकता है।

ध्यान दें: handshake पकड़ने के लिए हमलावर को पास होना और अक्सर victim को disconnect करना पड़ता है — यह बिना अनुमति अपराध है। यहाँ हम सिर्फ़ यह समझ रहे हैं कि सुरक्षा कैसे काम करती है।

Wi-Fi पर आम कमज़ोरियाँ

  • कमज़ोर password: नाम, मोबाइल नंबर या "12345678"।
  • WPS चालू: WPS PIN के ज़रिए जुड़ना आसान हो जाता है — इसे बंद रखें।
  • पुराना firmware: router में known bugs रहते हैं।
  • Default admin password: router के admin panel का password न बदलना।
  • Guest network का ग़लत setup: guest को internal network तक पहुँच मिल जाना।

अपना नेटवर्क सुरक्षित करने के कदम

  1. Router पर WPA2/WPA3 और 16+ अक्षरों का random password रखें।
  2. Router का admin password बदलें और remote management बंद करें।
  3. WPS बंद करें और firmware अपडेट रखें।
  4. मेहमानों के लिए अलग guest network बनाएँ।
  5. पुराने devices को network से हटाएँ और devices की सूची देखते रहें।

Python से Wi-Fi की जानकारी

Linux में आस-पास के networks की सूची देखने के लिए command-line tools होते हैं। Python से उनका output पढ़ा जा सकता है:

import subprocess

out = subprocess.check_output(["nmcli", "-t", "-f", "SSID,SIGNAL,SECURITY", "dev", "wifi"])
for line in out.decode().splitlines():
    print(line)

यह सिर्फ़ अपने आस-पास के networks की signal और security जानकारी दिखाता है — कोई हमला नहीं। scan करते समय भी यह याद रखें कि किसी के नेटवर्क पर जुड़ना या test करना अनुमति के बिना ग़लत है।

  • WPS बंद, firmware अपडेट, लंबा Wi-Fi password
