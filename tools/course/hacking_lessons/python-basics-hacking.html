Python security कामों की सबसे आम भाषा है — क्योंकि इसमें छोटा script जल्दी बनता है, बहुत सी libraries मिलती हैं और पढ़ना आसान है। इस लेसन में वही Python दोहराएँगे जो आगे के tools में चाहिए: variables, data types, conditions, loops, functions और error handling।

Variables और Data Types

Variable एक नाम वाला डिब्बा है जिसमें value रखी जाती है। Python में type बताने की ज़रूरत नहीं:

host = "192.168.56.101"   # string
port = 22                 # integer
timeout = 2.5             # float
is_open = True            # boolean

Security scripts में सबसे ज़्यादा string (IP, URL, नाम), integer (port, count) और list (कई hosts या ports) इस्तेमाल होते हैं।

Conditions — शर्त के हिसाब से फ़ैसला

if port == 22:
    print("SSH port khula hai")
elif port == 80:
    print("Web server")
else:
    print("Koi aur service")

Scanning tools में यही logic काम आता है — port 22 खुला है तो SSH, 80 या 443 खुला है तो web, 3306 खुला है तो database। शर्तों से ही output को अर्थ मिलता है।

Loops — एक ही काम बार-बार

ports = [21, 22, 80, 443, 3306]
for p in ports:
    print("checking", p)

Port list, host list, file की पंक्तियाँ — सब पर loop चलता है। जहाँ अनगिनत बार चलाना हो वहाँ while इस्तेमाल होता है, पर हमेशा एक रुकने की शर्त रखें, वरना script फँस जाएगी।

Functions — code को दोबारा लिखने से बचना

def check_host(host, port):
    print(f"{host}:{port} check ho raha hai")
    return True

check_host("192.168.56.101", 80)

Function में वही काम एक जगह लिखा जाता है और कहीं से भी बुलाया जा सकता है। बड़े tool में हर काम का अलग function होना चाहिए — scan, parse, report — इससे code पढ़ना और ठीक करना आसान होता है।

List, Dictionary और File

  • List: hosts = ["10.0.0.1", "10.0.0.2"] — क्रम वाली सूची।
  • Dictionary: {"host": "10.0.0.1", "port": 80} — नाम-वैल्यू जोड़े, JSON जैसा।
  • File: with open("hosts.txt") as f: — सूची फ़ाइल से पढ़ना।

Scanner का result अक्सर dictionary में रखा जाता है, फिर JSON या CSV में सेव किया जाता है — ताकि रिपोर्ट बन सके।

Error Handling — script का न रुकना

try:
    value = int(input("Port: "))
except ValueError:
    print("Sirf number daalein")

Network tools में timeout, बंद host और गलत input आम हैं। try/except के बिना एक error पूरा script रोक देता है; इसके साथ script अगले host पर आगे बढ़ जाता है।
