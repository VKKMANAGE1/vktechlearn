2How to use

  1. Choose one or more images.
  2. Pick the rotation angle.
  3. Tick flip if you also want a mirror image.
  4. Press Rotate images and download.

3Rules & limits

  • Only right-angle rotations are supported here; fine tilts need the photo editor.
  • Flip mirrors the image, which is handy for correcting selfies.
  • Output keeps each file's original format.
  • Maximum input size is 40 MB per image.
