2How to use

  1. Choose one or more images.
  2. Pick percent or pixel width.
  3. Press Resize images.
  4. Download the resized image or the ZIP.

3Rules & limits

  • Aspect ratio is always kept, so height follows the width automatically.
  • Upscaling beyond 200% looks soft — use the Upscale tool for a smoother result.
  • Output keeps the original format (JPEG stays JPEG, PNG stays PNG).
  • Maximum input size is 40 MB per image.
