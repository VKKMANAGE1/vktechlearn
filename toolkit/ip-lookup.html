इस टूल का उपयोग कैसे करें (How to use this tool)

यह टूल आपके या किसी भी IP पते के बारे में जानकारी ढूंढने के लिए बनाया गया है। इसका उपयोग करने के लिए इन सरल चरणों का पालन करें:

  1. स्वचालित खोज (Automatic Lookup)

    जब आप पेज खोलते हैं, तो यह टूल स्वचालित रूप से आपके वर्तमान IP पते का पता लगाता है और उसकी जानकारी (जैसे देश, शहर और ISP) दिखाता है। यह जानकारी सीधे मैप पर भी प्रदर्शित होती है।

  2. कोई अन्य IP पता दर्ज करें (Enter another IP Address)

    यदि आप किसी और IP पते की जानकारी चाहते हैं, तो "Enter IPv4 or IPv6" फ़ील्ड में उस IP पते को टाइप करें। आप IPv4 (जैसे 8.8.8.8) या IPv6 (जैसे 2001:4860:4860::8888) दोनों को दर्ज कर सकते हैं।

  3. खोजें बटन पर क्लिक करें (Click the Lookup Button)

    IP पता डालने के बाद, "Lookup IP" बटन पर क्लिक करें। टूल उस IP पते से संबंधित सभी उपलब्ध जानकारी प्राप्त करेगा और उसे स्क्रीन पर दिखाएगा। मैप पर भी स्थान अपडेट हो जाएगा।

  4. परिणाम देखें (View Results)

    "Details" सेक्शन में आपको IP पता, देश, शहर, ISP और टाइमज़ोन जैसी जानकारी मिलेगी। "Map" सेक्शन में आप उस स्थान को मानचित्र पर देख सकते हैं।

कृपया ध्यान दें: यह टूल सार्वजनिक IP पतों के लिए बनाया गया है। निजी नेटवर्क पते (जैसे 192.168.x.x) का उपयोग करने पर सही परिणाम नहीं मिलेंगे।
