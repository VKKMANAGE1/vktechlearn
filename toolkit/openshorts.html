OpenShorts — long videos into vertical clips

Paste a YouTube link or upload a file: OpenShorts finds the strongest moments, cuts them into 9:16 clips, adds captions, reframes for faces, and gives you a real editor. Free, open source, no watermark and no plans. It runs on your own computer or server.

100% free No watermark No limits or credits MIT licence

→What you get

AI moment picking

Ranks the transcript scene by scene, keeps 3–15 moments of 15–60 seconds with a virality score.

Works with no key

A free offline picker scores the transcript itself; a Gemini key or a local Ollama model upgrades the selection.

Smart 9:16 reframing

Face-tracked crop, blurred background, two-speaker split or screencast layout — picked per video.

Auto captions

Word-level timestamps from Whisper, several caption styles, burned into the clip and downloadable as SRT.

Real clip editor

Word-level cuts, extra segments, framing changes and fast re-renders — not a preview mock-up.

Hooks and titles

An opening line for the clip, editable in text, font, style and position, plus titles for each platform.

YouTube Studio

Titles, descriptions with timestamps and thumbnails, ready to upload (key needed for the AI parts).

API and MCP

Same pipeline over REST, plus an MCP endpoint for Claude or ChatGPT-style agents.

→How to run it

This is a self-hosted tool: it needs Python and ffmpeg, so it cannot run inside a static page like the rest of this toolkit. You install it once on your computer or a small server, then open the dashboard in your browser.

  1. Install the requirements: Python 3.12, ffmpeg, and about 8 GB of RAM for comfortable CPU work (an NVIDIA GPU makes it much faster).
  2. Get the code and the Python packages: create a virtual environment and install requirements.txt; install the dashboard with npm install.
  3. Start it: the API runs on port 8000 and the dashboard on port 3000. Paste a link or upload a video and the clips land in the output/ folder.
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
(cd dashboard && npm install)
./start.sh
Heads-up: the free edition has no subscription, credits or watermark, and it needs no API key to clip a video. Optional keys only add features: Gemini or a local model for smarter moment picking, ElevenLabs for dubbing, fal.ai for AI actors, Upload-Post for auto-publishing.

→Good to know

A 110-second test video took about three minutes to become two finished 1080×1920 clips on a two-core machine. On CPU, budget roughly 3–5 minutes of processing for every minute of source; on a GPU it is closer to real time. Everything stays on your machine — no upload to a third-party service.
