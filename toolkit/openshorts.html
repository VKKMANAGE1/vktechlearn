OpenShorts — long videos into vertical clips

Paste a YouTube link or upload a file: OpenShorts finds the strongest moments, cuts them into 9:16 clips, adds captions, reframes for faces, and gives you a real editor. Free, open source, no watermark and no plans. It runs on your own computer or server.

100% free No watermark No limits or credits MIT licence

→What you get

AI moment picking

Ranks the transcript scene by scene, keeps 3–15 moments of 15–60 seconds with a virality score.

Can run without Google

Point LLM_BASE_URL at Ollama, LM Studio or vLLM and the moment picker stays on your own machine.

Smart 9:16 reframing

Face-tracked crop, blurred background, two-speaker split or screencast layout — picked per video.

Auto captions

Word-level timestamps from Whisper, several caption styles, burned into the clip and downloadable as SRT.

Real clip editor

Word-level cuts, extra segments, framing changes and fast re-renders — not a preview mock-up.

Hooks and titles

An opening line for the clip, editable in text, font, style and position, plus titles for each platform.

YouTube Studio

Titles, descriptions with timestamps and thumbnails, ready to upload (key needed for the AI parts).

API and MCP

Same pipeline over REST, plus an MCP endpoint for Claude or ChatGPT-style agents.

→How to run it

This is a self-hosted tool: it needs Docker, Python and ffmpeg under the hood, so it cannot run inside a static page like the rest of this toolkit. You install it once on your computer or a small server, then open the dashboard in your browser. These are the upstream project's own steps.

  1. Install Docker and Docker Compose. A machine with 8 GB of RAM is enough for CPU work; an NVIDIA GPU makes it much faster.
  2. Clone the repository and copy the example environment file. S3 backup is optional, so the file can stay empty for a first run.
  3. Start the stack with Docker Compose. The backend comes up on port 8000 and the dashboard on port 5175.
  4. Add your keys in Settings inside the dashboard: Google Gemini is required for the AI features, and fal.ai, ElevenLabs and Upload-Post unlock AI Shorts, voice dubbing and auto-posting.
git clone https://github.com/mutonby/openshorts.git
cd openshorts
cp .env.example .env
docker compose up --build

# then open http://localhost:5175
Costs: the software is free and MIT licensed, with no subscription and no watermark on your own machine. You bring your own keys, and each one has a free tier: Gemini (free tier available), ElevenLabs, Upload-Post (10 free uploads a month) and fal.ai (pay per use, only for AI Shorts). No Google key? Set LLM_BASE_URL to a local Ollama or LM Studio server and the clip pipeline stays fully local.

→Good to know

On a typical CPU an 8-minute video takes about 5–8 minutes to clip; with an NVIDIA GPU it is closer to a minute. Everything stays on your machine — the video is never uploaded to a third-party service, and only the transcript goes to Gemini (or to your own local model if you set one).
