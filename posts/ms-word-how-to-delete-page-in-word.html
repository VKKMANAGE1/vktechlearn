MS Word में पेज डिलीट कैसे करें | How to Delete Page in Word

क्या आप MS Word में गलती से extra page डाल बैठे हैं और अब उसे delete करना चाहते हैं? Word में पेज डिलीट करना आसान है, चाहे आप Windows, Laptop या Mobile App इस्तेमाल कर रहे हों। इस ब्लॉग में हम step by step process बताएंगे।

1. Laptop / Desktop Version में Page Delete करना

Method 1: Backspace या Delete Key से

सबसे आसान तरीका है की:

  • Delete करना चाहते पेज पर जाएँ।
  • Keyboard में Backspace या Delete key दबाएँ।
  • Extra empty paragraph या blank lines remove हो जाएँगे।

Method 2: Navigation Pane से

Word में Navigation Pane का use कर सकते हैं:

  • View tab में जाएँ और Navigation Pane select करें।
  • Pages section में उस पेज को चुनें जिसे delete करना है।
  • Content select करें और Delete press करें।

Method 3: Go To Feature

Specific page delete करने के लिए:

  • Ctrl + G press करें।
  • Page number डालें और Enter press करें।
  • Content select करें और Delete दबाएँ।

2. Word Mobile App में Page Delete करना (Android / iOS)

Mobile App में भी extra page delete करना आसान है:

  • Document खोलें और उस पेज पर scroll करें।
  • Text को long press करके select करें।
  • Delete या Cut का option चुनें।
  • Extra blank page remove करने के लिए backspace icon use करें।

3. Blank Page को Remove करना

कभी-कभी Word में blank page add हो जाता है। इसे हटाने के लिए:

  • Paragraph marks दिखाने के लिए Home → Show/Hide ¶ select करें।
  • Extra paragraph या page break select करें और delete दबाएँ।
  • Manual page break हटाने के लिए, page break select करके delete करें।

4. Section Breaks Delete करना

Section break भी extra page create कर सकता है।

  • Show/Hide ¶ enable करें।
  • Section break select करें।
  • Delete press करें।

5. Page Content Select करके Delete करना

Full page delete करना:

  • Mouse से पूरा content select करें।
  • Right click करके Cut या keyboard से Delete press करें।
  • इससे पूरा पेज हट जाएगा।

6. Tips और Tricks

  • Always Save document before deleting pages.
  • Extra blank pages usually come from empty paragraph marks or page breaks.
  • Use Navigation Pane for easier page selection, especially in large documents.
  • Mobile users should enable Editing Mode before selecting content.
  • Undo option (Ctrl + Z) हमेशा ready रखें अगर गलती से delete कर दिया।

7. Frequently Asked Questions (FAQ)

Q1. क्या मैं multiple pages एक साथ delete कर सकता हूँ?

Yes, Navigation Pane या content select करके एक साथ multiple pages delete किया जा सकता है।

Q2. Word में blank page हमेशा delete क्यों नहीं होता?

Mostly इसका कारण extra paragraph marks या section breaks होते हैं। Show/Hide ¶ option enable करके इन्हें select और delete करें।

Q3. क्या Mobile App में भी page break delete किया जा सकता है?

Haan, Long press करके content select करें और Cut/Delete option use करें।

8. MS Word Page Delete के लिए Step by Step Summary

  • Open Document → Navigate to Page → Select Content → Delete / Backspace
  • Navigation Pane → Page Select → Delete
  • Ctrl + G → Page Number → Select → Delete
  • Show/Hide ¶ → Extra Paragraph/Break → Delete
  • Mobile App → Long Press → Select → Delete
