📤 Extract Pages

Pull out just the pages you need — for example 1,3 and 5-7 — into a new PDF.

Split PDFMerge PDFRotate PDF

1Upload & set options

One PDF file, up to 50 MB.
Commas for single pages, hyphen for ranges.
No file selected yet.

2How to use

  1. Choose the PDF file.
  2. Type the pages you need, e.g. 1,3,5-7.
  3. Set the output filename.
  4. Press Extract pages and download.

3Rules & limits

  • Pages are kept in the order they appear in the document.
  • The page range cannot be empty — this tool always needs a selection.
  • For every page, use Split PDF with an empty range instead.
  • Maximum file size is 50 MB.
