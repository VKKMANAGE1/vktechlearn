📊 PDF to PowerPoint

Turn every PDF page into a slide in a .pptx presentation.

PDF to WordPDF to ExcelJPG to PDF

1Upload & set options

One PDF page = one slide.

2How to use

  1. Choose the PDF you want to turn into slides.
  2. Press Convert to PowerPoint.
  3. Each page becomes one 16:9 slide, first line as the title.
  4. Download converted.pptx.

3Rules & limits

  • Slides contain text only — images and exact positions are not transferred.
  • Long pages are split into a title plus body text, capped per slide.
  • Scanned PDFs need OCR PDF first, otherwise slides come out empty.
  • Maximum file size is 50 MB.
