2How to use

  1. Choose the original PDF and the revised PDF.
  2. Press Compare.
  3. Read the changed lines, then scroll through the side-by-side pages.
  4. Nothing is uploaded; the comparison stays on your device.

3Rules & limits

  • The comparison is visual plus a line-by-line text diff — no file is downloaded.
  • Pages are paired by number, so inserted pages show as differences from that point on.
  • Image-only changes are only visible in the side-by-side view.
  • Maximum file size is 50 MB per file.
