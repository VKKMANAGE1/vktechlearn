📑 Excel to PDF

Print a spreadsheet as a tidy PDF table, sheets one after another.

Word to PDFPDF to ExcelPowerPoint to PDF

1Upload & set options

Only .xlsx files.

2How to use

  1. Choose an .xlsx spreadsheet.
  2. Press Convert to PDF.
  3. Each sheet becomes a landscape table; the header row repeats on every page.
  4. Download spreadsheet.pdf.

3Rules & limits

  • Cell values are printed as plain text; formulas are not evaluated and styles are lost.
  • Very wide sheets are squeezed — keep print areas narrow for best results.
  • Only .xlsx is supported (not .xls).
  • Maximum file size is 50 MB.
