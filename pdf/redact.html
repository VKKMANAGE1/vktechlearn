⬛ Redact PDF

Drag black boxes over sensitive areas and save a file where that content is gone.

1Upload & set options

No boxes yet.

2How to use

  1. Choose the PDF and go to the page you want to redact.
  2. Drag a box over each sensitive area — add as many as you need.
  3. Use Undo or Clear page to fix mistakes.
  4. Press Save redacted PDF.

3Rules & limits

  • Redacted pages are flattened to images, so the covered text is really removed, not just hidden.
  • Repeat the tool for other pages; each run only changes the page shown.
  • Pages without boxes keep their original text and quality.
  • Maximum file size is 50 MB.
