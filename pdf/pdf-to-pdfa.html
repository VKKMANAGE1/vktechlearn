🏛️ PDF to PDF/A

Flatten a PDF into an archive copy with an sRGB profile and PDF/A metadata.

Compress PDFRepair PDFPDF Info

1Upload & set options

2How to use

  1. Choose the PDF you want to archive.
  2. Press Create archive PDF.
  3. Pages are flattened to images and tagged with sRGB + PDF/A metadata.
  4. Download archive.pdf.

3Rules & limits

  • Pages become images, so text is no longer selectable or searchable.
  • This produces an archive-ready file with PDF/A-2b metadata and an sRGB output intent, but it is not certified — certification needs a validator such as veraPDF.
  • Scanned documents and office exports archive best with this method.
  • Large documents take longer because every page is re-rendered.
