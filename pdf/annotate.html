🖍️ PDF Annotation

Drop a coloured highlight box with your note anywhere on a page.

No file selected yet.

2How to use

  1. Choose the PDF you want to annotate.
  2. Type the note and the page number.
  3. Pick a highlight colour and set the X/Y position (points from the bottom-left).
  4. Press Add annotation and download.

3Rules & limits

  • Position is measured in PDF points from the bottom-left corner (A4 = 595 × 842).
  • The note is drawn as a new layer; the original text is not changed.
  • Repeat the tool to add more notes — each run adds one box.
  • Maximum file size is 50 MB.
