📝 PDF to Word

Extract the text of a PDF into an editable Word (.docx) document.

1Upload & set options

Text-based PDFs work best. Scans need OCR first.
No file selected yet.

2How to use

  1. Choose the PDF you want to convert.
  2. Press Convert to Word — text is read page by page.
  3. Wait for the green message with the paragraph count.
  4. Download converted.docx and open it in Word or Google Docs.

3Rules & limits

  • Only selectable text is exported — layout, images and columns are not recreated.
  • Scanned PDFs have no text layer; run OCR PDF first.
  • Each PDF page starts on a new Word page.
  • Maximum file size is 50 MB.
