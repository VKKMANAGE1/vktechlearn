🔍 OCR PDF

Add a searchable text layer to scanned pages so you can search and copy the text.

PDF to WordScan to PDFAI Summarizer

1Upload & set options

Works best on clean, straight scans at 200 DPI or more.
The text will appear here.

2How to use

  1. Choose a scanned PDF.
  2. Pick the language that appears in the document.
  3. Press Run OCR — the engine downloads on first use.
  4. Download searchable.pdf and try searching for a word.

3Rules & limits

  • The first run downloads the OCR engine (~15 MB) and language data — later runs are cached.
  • English is the most accurate; Hindi needs cleaner, larger scans.
  • Text is placed as an invisible layer, so positions are approximate but search works.
  • Scanned pages only — pages that already have text keep their original layer.
