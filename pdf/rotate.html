🔄 Rotate PDF

Turn every page of a PDF by 90°, 180° or 270° so scans and photos sit upright.

Merge PDFSplit PDFCompress PDF

1Upload & set options

One PDF file, up to 50 MB.
No file selected yet.

2How to use

  1. Choose the PDF that needs rotating.
  2. Pick the angle: 90° clockwise, 180°, or 270°.
  3. Press Rotate PDF.
  4. Download the rotated file and check the preview.

3Rules & limits

  • The angle is applied to every page in the file.
  • Rotation is saved in the PDF itself, so it opens correctly everywhere.
  • Running the tool twice adds the angles together.
  • Maximum file size is 50 MB.
