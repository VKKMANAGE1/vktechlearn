🧾 PDF Forms

Fill interactive PDF form fields, or add a new text field to any page.

AnnotationSign PDFAdd Text

1Upload & set options

Add a text field

2How to use

  1. Choose a PDF with form fields and press Detect fields.
  2. Type into the fields that appear.
  3. Press Save filled PDF (tick flatten to lock the answers).
  4. To add a field instead, use the “Add a text field” section.

3Rules & limits

  • Fields are detected from the PDF's AcroForm — forms flattened into an image cannot be filled.
  • “Flatten” makes answers permanent and removes the editable fields.
  • New fields can be added at any position, measured in points from the bottom-left.
  • Maximum file size is 50 MB.
