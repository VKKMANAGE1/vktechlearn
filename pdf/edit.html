✏️ Add Text to PDF

Write new text on top of any page — labels, corrections, stamps or short notes.

AnnotationSign PDFWatermark

1Upload & set options

One PDF file, up to 50 MB.
No file selected yet.

2How to use

  1. Choose the PDF you want to write on.
  2. Type the text and the page number.
  3. Set font size, colour and X/Y position.
  4. Press Add text and download the file.

3Rules & limits

  • This adds a new text layer — existing text is not removed or rewritten.
  • Replacing existing words needs OCR and server processing, which this tool does not do.
  • Position is measured from the bottom-left of the page in points.
  • Only Latin text is supported (Helvetica font).
