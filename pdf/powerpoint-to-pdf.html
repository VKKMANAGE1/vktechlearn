📽️ PowerPoint to PDF

Turn a .pptx deck into a landscape PDF, one slide per page.

Word to PDFExcel to PDFPDF to PowerPoint

1Upload & set options

Only .pptx files (PowerPoint 2007+).

2How to use

  1. Choose a .pptx presentation.
  2. Press Convert to PDF.
  3. Each slide becomes one landscape A4 page.
  4. Download slides.pdf.

3Rules & limits

  • Slide text is reproduced; images, shapes and animations are not.
  • Only .pptx is supported — save old .ppt files as .pptx first.
  • Very long slides are cut off at the bottom of the page.
  • Maximum file size is 50 MB.
