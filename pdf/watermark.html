💧 Add Watermark

Stamp text such as CONFIDENTIAL or DRAFT diagonally across every page.

Protect PDFAnnotationSign PDF

1Upload & set options

One PDF file, up to 50 MB.
No file selected yet.

2How to use

  1. Choose the PDF you want to watermark.
  2. Type the watermark text, size and opacity.
  3. Pick a colour (grey, red, blue or black).
  4. Press Add watermark and download the file.

3Rules & limits

  • The watermark is drawn diagonally on every page.
  • Opacity 0.1–0.8 keeps the text visible without hiding content.
  • Watermark text is limited to the Latin alphabet (Helvetica font).
  • Maximum file size is 50 MB.
