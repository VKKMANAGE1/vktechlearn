✂️ Split PDF

Pick the pages you want from a PDF and save them as a new, smaller document.

1Upload & set options

One PDF file, up to 50 MB.

No file selected yet.

2How to use

  1. Choose the PDF you want to split.
  2. Type the page range — for example 1-3,5; leave it empty for all pages.
  3. Set the output filename.
  4. Press Split PDF and download the result.

3Rules & limits

  • Page numbers start at 1 and must exist in the document.
  • Use commas for single pages and a hyphen for ranges: 1,3,5-7.
  • Empty page box = every page is copied.
  • Maximum file size is 50 MB.
