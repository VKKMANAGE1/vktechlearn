🔒 Protect PDF

Password-protect a PDF with real AES-256 encryption and choose what the reader may do.

WatermarkSign PDFPDF Info

1Upload & set options

One PDF file, up to 50 MB.

2How to use

  1. Choose the PDF you want to protect.
  2. Enter an open password (minimum 4 characters).
  3. Optionally set an owner password and allow printing or copying.
  4. Press Protect PDF and download the encrypted file.

3Rules & limits

  • The open password is required — without it the PDF cannot be opened.
  • Encryption is AES-256 (PDF 1.7), applied in your browser.
  • Editing, annotating and page extraction are blocked by default.
  • There is no password recovery — store the password safely.
  • Already-protected PDFs must be unlocked before using this tool.
