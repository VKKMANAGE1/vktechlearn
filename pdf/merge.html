🧩 Merge PDF

Combine two or more PDF files into a single document, in the order you choose.

Split PDFExtract PagesCompress PDF

1Upload & set options

Pick 2 or more files. Each file can be up to 50 MB.
    No file selected yet.

    2How to use

    1. Select two or more PDF files with the file picker.
    2. Check the list — use ▲ ▼ to change the order, ✕ to remove a file.
    3. Press Merge PDFs and wait for the green message.
    4. Click Download merged.pdf to save the combined file.

    3Rules & limits

    • At least 2 PDF files are required.
    • Each file can be up to 50 MB.
    • Password-protected PDFs are rejected — unlock them first.
    • Your files stay in the browser; nothing is uploaded.
