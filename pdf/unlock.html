🔓 Unlock PDF

Remove a PDF password (when you know it) and save an unrestricted copy.

Protect PDFRepair PDFPDF Info

1Upload & set options

2How to use

  1. Choose the protected PDF.
  2. Type its open password (leave empty for files that only had owner restrictions).
  3. Press Unlock PDF.
  4. Download the unrestricted copy.

3Rules & limits

  • You must know the password — this tool cannot crack or guess it.
  • Files that open without a password but block printing or copying unlock with an empty password.
  • Removing protection is only legitimate on your own documents.
  • Maximum file size is 50 MB.
