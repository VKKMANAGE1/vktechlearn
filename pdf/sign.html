✍️ Sign PDF

Draw your signature with a mouse or finger and place it on any page.

AnnotationProtect PDFAdd Text

1Upload & set options

Draw slowly for a smooth line.
One PDF file, up to 50 MB.

2How to use

  1. Draw your signature in the white pad (mouse, stylus or finger).
  2. Choose the PDF, the page and the scale.
  3. Set X/Y position — 400/100 places it bottom-right on A4.
  4. Press Apply signature and download.

3Rules & limits

  • The signature is a transparent PNG, so the page content stays visible.
  • Use X ≈ 400 and Y ≈ 100 for a bottom-right signature on an A4 page.
  • Page numbers start at 1.
  • Maximum file size is 50 MB.
