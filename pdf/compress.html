🗜️ Compress PDF

Shrink image-heavy and scanned PDFs by re-rendering pages at a smaller size.

Merge PDFRotate PDFSplit PDF

1Upload & set options

One PDF file, up to 50 MB.
No file selected yet.

2How to use

  1. Choose the PDF you want to shrink.
  2. Pick a compression level: light, balanced, strong or maximum.
  3. Press Compress PDF and watch the size comparison.
  4. Download the smaller file (or the original if it was already optimised).

3Rules & limits

  • Pages are re-rendered as images, so text is no longer selectable.
  • Best results on scanned documents, photo PDFs and screenshot exports.
  • If the result would be larger, the original file is offered instead.
  • Large files take longer — keep the tab open until it finishes.
