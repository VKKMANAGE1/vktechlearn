🌐 HTML to PDF

Paste HTML (or text) and save it as a PDF through your browser's own print dialog.

Word to PDFPDF to MarkdownBlank PDF

1Upload & set options

Tip: keep CSS inline or in a <style> tag inside the pasted HTML.

2How to use

  1. Paste your HTML or plain text into the box.
  2. Press Open print view — a new tab opens with your content.
  3. In the print dialog choose Destination → Save as PDF.
  4. Save the file — headings, lists, tables and links keep their formatting.

3Rules & limits

  • The PDF is created by your browser's print engine, so this page must be allowed to open pop-ups.
  • Scripts and external stylesheets inside the pasted code are ignored for safety.
  • Remote URLs cannot be fetched here — paste the HTML, or open the URL and use your browser's Print.
  • Images must be reachable by your browser (full https URLs or inline data).
